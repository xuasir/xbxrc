# 串流菜单快捷键图示子页

## Status

- Last Updated: 2026-11-12

## Background

现有“通用”页面提供串流菜单和诊断菜单的组合键录入。用户要求补齐清空操作，并将配置整理为与手柄布局一致的图示子页。复测发现现有快捷键录入未持有独占输入，实体 B 会触发页面返回。

## Goal

- “设置 → 串流体验”第一项进入串流菜单快捷键子页。
- 子页使用当前页面背景；内容区左上角为 Xbox 串流菜单按钮，左下角为诊断菜单按钮，距相邻外边均为 24px；按钮图标、尺寸及定位 CSS 与真实串流页共用。
- 子页沿用手柄布局的页头、图上选择、独占录入与焦点交互。
- 确认图上目标后独占录入 1–4 个标准 Xbox 输出按键或对应键盘绑定，全部释放后立即保存。
- 两个目标各自提供清空；空数组表示未绑定，两组都可为空。
- 录入期间提供固定状态与取消操作，完成或清空后恢复目标焦点，返回恢复设置入口。

## Scope

设置展示 schema、设置页操作、独立路由、现有 GamepadToolPage、串流按钮定位 CSS、菜单图标示意与快捷键编辑组件。配置继续复用 `stream_menu_shortcuts`、公共 InputController 和 Rust 配置保存合同。

## Plan

1. 在串流体验首个板块加入子页入口，通用页恢复现有外观、启动、反馈与更新排列。
2. 从串流页提取共用按钮定位样式，示意图复用两个实际图标按钮，并提供目标旁的独立动作插槽。
3. 子页复用快捷键录入和保存逻辑，补齐独占采集、清空、重复组合检查、焦点与生命周期清理。
4. 验证实体 B、菜单组合与键盘录入、独立清空、恢复默认、进出焦点和窄屏布局。
