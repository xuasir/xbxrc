## Background

[全页面审计](https://github.com/xuasir/xbxrc/blob/b864eb1733751b9a57ffdad65ee4bb496175bb71/dev-docs/validation/2026-11-06-pc-navigation-focus-audit/README.md)已经复现主机 / 设置往返的重复高亮、安装库返回主页的三个焦点标记、登录按钮出现时空焦点，以及串流音量面板返回失效。生产引擎独立复现与真实 Vue 生命周期复现共 15 项行为断言失败，3 项夹具对照通过，原有定向 23 项回归通过。

问题集中于共享焦点有效性、DOM 标记与页面记忆、Scope 归属和异步生命周期。各页面沿用当前几何寻路；修复覆盖现有导航模块、壳层、页面恢复和弹层事件。

## Goal

1. 普通 UI 焦点同时满足连接、可用、可见和当前域归属；引擎状态、DOM 高亮与实际焦点一致。
2. 页面 / 分类 / 详情返回恢复明确来源；加载、筛选、刷新及节点重建时选择有效的邻近目标。
3. 弹层始终持有最上层焦点；关闭、缓存停用和卸载完整释放；迟到激活按会话身份失效。
4. 音量面板的 B / Esc 与 Tab 行为和其余串流弹层一致，关闭后沿用现有 focus sink。
5. 700px 及以下的一级导航按最新反馈采用贴底通栏毛玻璃，配合上沿圆角、细描边和柔和阴影，保留五个页面入口、背景选中态与既有焦点框；操作提示独立悬浮在导航上方12px，正文延伸至导航后方，避让包含导航及提示实际高度。提示高度变化后即时显露当前焦点并保留临时禁用来源；一级导航按用户要求保持无绿条。

## Behavior Contract

### 焦点有效性与空域

- 将候选可用性校验收在现有引擎中，由移动、默认 / 记忆 / 来源恢复、外部聚焦和实际提交共同使用。
- 检查节点连接、selector / 原生禁用、祖先 hidden / inert / 可见性及实际布局；视口外的可滚动节点继续属于候选。
- Stream 的 focus sink 明确标记为专用承接节点，支持程序化聚焦并消费持键释放；普通候选继续按 UI 有效性校验。
- 当前焦点失效时清理旧标记并重新选择。首次 A 在失效状态下只建立有效焦点，后续 A 执行确认。
- Back、页面 / 分类切换按 Scope 和业务归属分发，空候选时保留返回与切换能力。
- 所有节点临时禁用时，由当前域内的显式承接目标维持焦点；数据或 busy 状态恢复后按当前请求身份选择可用节点。

### 单一高亮与来源记录

- 切换、失效、停用及卸载统一清理旧元素的 class / attribute；缓存节点回插后由当前 owner 重新应用高亮。
- 共享引擎提供当前焦点的只读访问，页面保存与区域识别使用此入口。
- 页面记录按路由身份、账号 / 好友 / 主机 / 游戏身份和分类键组织，元素重建时用稳定 ID 解析当前节点。
- 显式点击导航保留操作来源；LB/RB 恢复目标页记忆或既有主入口；详情返回恢复列表来源。
- 来源删除或禁用时优先采用同页邻近候选，再回退到当前 Scope 入口。分类操作保持目标分类；内容滚动继续恢复分类位置。
- 临时禁用的来源单独记录；可用后恢复原位置。用户继续移动、确认、返回或切换时取消等待，以最新操作为准。

### Scope 与异步时序

- 激活请求携带实例 / 代际身份，nextTick 与 rAF 提交时检查 mounted、active、当前路由和 owner。
- KeepAlive 停用释放 Scope 与待执行请求，重新激活产生当前请求；首次 mounted / activated 合并为幂等激活。
- 最上层校验采用有效注册与当前元素。过期注册清理与新实例注册按各自身份执行。
- 下层重复激活保留上层焦点；背景页面的恢复请求在当前上层释放后重新校验来源。
- 页面恢复与 Transition 内容进入协调，来源恢复在当前内容就绪后执行；快速页面 / 分类切换以最后有效请求为准。
- 嵌套确认取消回父编辑器，父层与确认同时关闭回页面来源，沿用现有返回链。

### 弹层与串流

- 音量面板消费当前 Scope 的 B / Escape，并在有效候选内循环 Tab / Shift+Tab。
- busy 或空候选的弹层保持自身焦点边界，按现有 busy 关闭规则处理返回。
- Stream 关闭恢复检查页面会话与当前弹层，后续打开的弹层持有自己的焦点，游戏输入归属继续由现有 controller 管理。
