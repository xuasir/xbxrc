## Background / Goal

按[已确认设计](../isu/2026-11-05-pc-console-library-my-pages-design.md)接入对应主机的安装游戏子页与“我的”账户好友、成就、累计统计、Xbox 相册四页。保留当前壳层及主题，二级导航复用 SettingSidebar，网格间距 16px，刷新采用 36px 图标。

## Scope

- Vue 页面、路由归属、头像入口、一级导航顺序“主机 / 云游戏 / 我的 / 控制器 / 设置”。
- xbox-webapi 共享 HTTP 查询与 DTO；Tauri data 服务负责认证、限量并发和部分失败，当前 typed RPC 提供桌面消费。
- 主机安装列表、存储与状态；游戏历史、成就分页、好友详情与成就对比；累计时长；双来源媒体分页、预览和主动系统保存。
- 游戏身份分别保留商品 ID、Xbox title ID、串流 title ID；主机查询使用 console identity，串流沿现有 serverId 流程。
- 页面保留筛选/滚动/焦点；迟到响应检查当前账号及请求代际。隐私、缺值、空结果、局部失败使用可见反馈。
- 周/月快照、指定游戏启动、远程安装卸载与消息/派对按设计作为后续独立任务。

## Risks / Execution Notes

- Xbox 服务权限和覆盖率依真实账户；离线安装查询、隐私、限流和媒体失效须保留明确错误及已有成功内容。
- 时长为累计数据，聚合标注已加载且有时长数据的覆盖范围；零值和缺值分开显示。
- 媒体 continuation 保留 POST；系统保存从重新查询的服务媒体地址下载，避免接受任意前端 URL。
- 2026-11-05：开始正式接入；沿现有 Tauri + Vue 3 + TypeScript + Rust 及几何导航引擎。
- 2026-11-05：按用户反馈收敛元素与背景融合。返回与关联入口采用透明文字操作；账户、统计和容量使用留白/细分隔线；刷新沿用 36px 图标。好友详情的游戏历史使用二级标题，主机摘要压紧以提高窄窗口首屏内容量。
- 2026-11-05：按用户反馈补强文字可读性。正文与列表名称/数值使用 16px；时间、进度、容量说明和媒体时长使用 14px，辅助色向当前主题主文字色混合 20%，保持实色和 1.5 行高。局部字号调整覆盖新增页面，壳层及原有页面继续使用既有 token。
- 2026-11-05：交付审计补齐刷新合同。已浏览页数随账号缓存保留，刷新按新游标重读相同范围；后续页失败保留旧成功内容。主机页重新激活和手动刷新同步更新设备事实，离开、换设备及换账号时丢弃迟到响应，设备查询失败后等待有效状态启用串流。
- 2026-11-05：主机游戏封面按商品身份匹配，复用现有商品分批、图片归一化与市场/语言选择。封面查询受 8 秒总预算约束，失败仍保留安装事实。好友资料与关系状态同步刷新，游戏详情呈现局部错误，相册保存反馈按当前账号及媒体身份接收。
- 2026-11-05：列表筛选、删除和末页入口移除时，通过现有导航引擎将焦点交给邻近有效项；头像菜单默认聚焦“进入我的”，支持返回关闭。
