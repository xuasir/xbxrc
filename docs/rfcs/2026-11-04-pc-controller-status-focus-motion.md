## Decisions

- 手柄一级页内分为连接状态 / 手柄设置；恢复设备图、连接数量、当前设备、标准映射、震动能力、输入状态和实时控件展示，读取现有 InputController。当前合同未提供的电量 / USB、蓝牙信息显示未知。
- 云游戏标题、搜索和分类占独立透明区域，内容在下方滚动，延续设置标题方向；搜索改为线框放大镜。
- 分段已选态使用明确底色和淡色边框；按用户续修移除勾选标记。深色已选底色为白色 24% / 常态约 4.3%，浅色已选蓝灰 18% / 常态 5%；聚焦和悬停时继续保留当前选中底色。
- 焦点按用户续修使用淡雅主题绿到青蓝渐变细环，配低强度光晕；共享轮廓采用 CSS mask，原生输入框沿用同色阴影。导航焦点与配置选中分别表达。
- 用户续修确认一级导航使用选中背板与焦点外环；侧边绿线仅用于设置 / 手柄二级分类。
- Logo 常态 / 悬停 / 聚焦保持透明底，聚焦通过轮廓表达。
- 主机标题和设备名称缩小，重点卡片使用弱渐变背景与毛玻璃；边框采用统一淡色。
- 页面、子页、设备切换、焦点进入、悬停 / 按下和云游戏区域滚动提供短动效；减少动态效果偏好即时关闭动画。
- 手柄子页用单根容器承接 Transition，兼容设置编辑器的多个弹层根节点；往返切换后恢复各自滚动位置。主机切换保留重点区最小高度。
- Vue / Tauri / InputController / 配置合同 / 几何导航边界保持当前主线。
