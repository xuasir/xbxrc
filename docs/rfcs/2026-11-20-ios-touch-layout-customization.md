## Background

2026-11-23 接续避让修复：串流操作层遵循原生安全区，正式 Surface 将窗口安全范围投影到全屏/竖屏下半区几何，绘制、命中和编辑位置共用同一范围；方向与安全区变化沿现有输入释放路径处理。[验收证据](../../dev-docs/validation/2026-11-23-ios-streaming-safe-area/README.md)接续记录左右横屏、竖屏和 iPad。

2026-11-23 用户追加界面要求：两个触屏子页按真实设备视口呈现。接续修改采用独立全屏画布和默认收起的设置面板；手机方向胶囊请求系统旋转，iPad 胶囊只读展示当前窗口方向并提示旋转设备或调整窗口。正式 Surface、位置归一化、竖屏下半区及草稿保存合同沿用。[本轮证据](../../dev-docs/validation/2026-11-23-ios-touch-workspace-refresh/README.md)记录接续验收。

用户要求将“控制器 → 触屏”从测试工具入口调整为日常配置入口：隐藏测试入口，支持拖动布局并保存本地模板，在上级切换模板，进入独立子页可视化调节当前布局的透明度和大小。

当前正式触屏已经复用 `TouchLayoutSurface`、`TouchInputAccumulator` 与 `StreamInputSession`，通用 Xbox 资源用于云游戏和本地主机串流；竖屏手柄视口位于下半区。触屏设置仍展示只读标准布局、透明度滑杆和测试入口。`MobilePreferences.normalized()` 将布局身份固定为 `classic`，正式覆盖层仅加载标准资源。

## Goal

1. 触屏上级菜单提供显示模式、布局模板选择、“自定义布局”和“触屏手柄调整”。
2. 自定义布局子页使用现有标准 Xbox 控件，支持拖动、恢复位置、命名与保存；保存后自动选中并能从上级菜单再次切换。
3. 调整子页渲染当前选中模板，透明度和大小变化立即反映在预览中，保存后用于本地与云游戏串流。
4. 保持标准 Xbox 图标、动作映射、多指输入、竖屏下半区与外接手柄归属合同。

## Scope

本轮覆盖 iOS 触屏设置、布局配置持久化、现有几何与渲染扩展、串流消费和对应自动验收。内置通用 Xbox 为唯一默认基准，本地模板复用其完整控件集及动作。

既有内部测试工具保留实现与测试用途，正式设置页隐藏测试入口。官方远程布局下载、游戏专属自动布局、动作重映射、云端模板同步、媒体与传输协议保持各自既有范围。

## Product Flow

### 上级触屏菜单

- “触屏手柄”：继续使用自动、始终显示、隐藏三种模式。
- “布局模板”：选择“通用 Xbox”或已保存的本地模板，显示当前模板名称。
- “自定义布局”：从当前模板建立编辑草稿，进入原生导航子页。
- “触屏手柄调整”：进入当前模板的外观调整子页。

透明度和大小统一在调整子页配置，原有测试分区从正式页面移除。

### 自定义布局子页

1. 页面顶部提供横屏、竖屏切换；画布展示对应方向的完整屏幕比例，竖屏控件限制在画布下半区。
2. 直接拖动控件调整位置；选中控件保留可见轮廓，拖动过程只更新位置草稿。
3. 使用模板名称输入框和“保存”操作。首次从通用 Xbox 保存创建本地模板；编辑本地模板保存更新同一模板。
4. 本地模板提供“另存为新模板”，便于保留多个布局；“恢复位置”恢复该方向的通用 Xbox 位置。
5. 保存后选中该模板并返回上级；本地模板的删除操作使用系统确认，删除当前模板后回到通用 Xbox。
6. 离开页面时丢弃尚未保存的草稿，既有模板保持已保存状态。

名称为空时使用自动编号名称，模板以独立 ID 区分。重名允许存在，自动名称避开已用名称。

### 触屏手柄调整子页

1. 显示当前模板名称与实际布局预览，横屏、竖屏预览使用同一几何策略。
2. “透明度”范围保持 20%～100%，默认 65%；“大小”范围为 75%～150%，默认 100%。
3. 滑杆更新实时预览，滑杆旁展示当前百分比；“恢复默认”将透明度和大小恢复默认。
4. “保存”写入当前模板外观并返回上级；离开时丢弃外观草稿。
5. 透明度和大小随各个模板独立保存。通用 Xbox 保留固定基准位置，并支持保存自身外观偏好。

## Storage Contract

沿 `MobilePreferences` 和 `AppSettingsStore` 的现有 Codable / UserDefaults 持久化保存，使用现有 `ios.settings.mobile.v2` 键及兼容 decoder，新增字段逐项提供默认值。

- `touchLayoutID`：当前模板 ID；`classic` 继续表示内置通用 Xbox。
- `touchOpacity`：继续保存通用 Xbox 的透明度，兼容既有安装的外观设置。
- `touchScale`：保存通用 Xbox 大小，默认 `1.0`。
- `touchLayoutTemplates`：本地模板集合，包含版本、独立 ID、名称、横竖屏控件中心位置及外观参数。
- 模板仅保存标准控件的稳定 ID 和位置覆盖，动作、图标、基础布局继续从随包通用 Xbox 资源读取。
- 控件位置按手柄可用视口保存为归一化中心坐标；竖屏坐标对应下半区视口，横屏坐标对应完整视口。未调整的控件沿标准位置。
- 模板集合最多保存 20 项；达到上限时仍可更新已有模板，并通过删除释放模板名额。
- 名称清理首尾空白并限制为 40 个字符，位置与外观过滤非有限数并归一化；仅保留当前标准布局支持的稳定控件 ID。
- 重复模板 ID、未知版本或损坏模板过滤；当前 ID 无对应有效模板时回到 `classic`。旧测试目录 ID 继续迁移至标准布局，已有透明度保持原值。
- 单次保存使用完整偏好快照，模板、选择和外观一起写入；草稿保留在子页局部状态。

## Geometry and Input Contract

1. 现有 `TouchLayoutGeometry` 先生成标准 sockets，再按当前方向的位置覆盖和大小参数生成最终 sockets。绘制、无障碍范围与命中读取同一结果。
2. 大小参数同时影响控件直径、单位距离与摇杆等内部几何；最小命中直径保持 44pt。
3. 控件中心按最终控件外缘钳制在视口安全边界内；画布缩放、设备旋转、模板切换和窗口尺寸变化均重新计算。竖屏所有控件外缘始终保留在下半区。
4. 编辑操作在现有 Surface 中采用拖动模式，拦截指针以修改草稿位置；编辑模式与预览模式持有独立本地 accumulator。
5. 编辑与预览保持本地输入终点，正式覆盖层继续经既有 `StreamInputSession.setTouchLayoutState()` 输出。
6. 正式覆盖层读取当前模板与外观。模板、位置、大小或方向变更时先取消旧指针和持续贡献，再原子重建 sockets，发布 neutral 状态。
7. 页面关闭、移除视图、后台和输入抑制继续使用原有统一取消路径，完整释放按钮、摇杆与扳机。
8. 模板选择与外观配置只作用于触屏，外接手柄继续按现有设备归属和映射提供输入。

## Risks

- 既有布局 ID 强制归一化规则会覆盖新模板选择，迁移需同时更新偏好校验和正式消费。
- 控件放大及拖到边缘容易出现绘制与命中偏差，必须在最终 socket 层统一变换及钳制。
- 横竖屏和不同设备比例改变可用空间，按方向保存归一化坐标并验证缩小窗口与尺寸边界。
- 编辑手势与游戏输入共享触摸表面，交互模式必须明确隔离，切换时完整取消已有输入。
