## Background

[已确认方案](../isu/2026-11-04-pc-play-xbox-visual-interaction-plan.md)固定通顶环境光、透明分组导航与底部提示、方形完整游戏封面、头像账户弹窗和完整设置页。当前数据、认证、串流和几何导航提供所需能力。

## Goal

在真实 Vue 应用交付一版统一字体、色值、边框、阴影、间距和状态反馈的 PC 界面。主动作与底部有效提示在常见 16:9 及较矮窗口可见。

## Scope

- 主题真源与别名、AppShell / 导航 / 底部提示、Home / 设备选择、XCloud / 方形 GameCard / 轨道、UserProfileMenu、设置材质与通顶标题栏。
- 现有 Rust 数据 / 认证 / 串流协议、配置 schema、几何导航引擎和 HUD 业务合同继续沿用。
- 云游戏按最近 / 新 / 全部 / 搜索组织；图片优先 tile，fallback poster，完整显示。

## Decisions

- 主题颜色和渐变在当前 foundation → semantic → alias 中定义；组件消费同一真源。
- 壳层保留稳定节点 ID 和 LB/RB 顺序。导航位置移到左侧；右上角保留品牌上下文和头像。
- 底部提示占据独立布局行，与滚动容器分离。壳层提供局部 Vue 上下文接收当前页与弹层提示，KeepAlive 激活 / 退出按来源身份清理；数据状态继续归原页面。
- 弹层继续使用 FocusScope；页面肩键切换只在壳层为最上层且输入归属有效时执行。账户增加原生 Tab 限定，关闭恢复来源。
- 主机选中仅更新重点区，串流动作保留目标 ID / consoleId 与状态参数；在线允许串流、待机允许远程管理时继续既有准备流程，其余状态提供刷新。
- 卡片默认透明、方形、contain；文字使用局部暗渐变。设置保留五类及保存 / 编辑 / 输入捕获。
- 浏览页根背景通顶，Tauri macOS 标题栏使用 Overlay；原生窗口操作和认证窗口仍由现有壳层承接。
