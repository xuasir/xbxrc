## 目标与范围

统一 iOS / iPad 五个根页及其子页的标题、正文、辅助事实和操作层级。信息成组使用卡片，少量互斥筛选直接横向切换，排序和大量动态选项使用有边界的菜单按钮。沿现有 SwiftUI 页面、Rust 桥接、数据 owner、原生 NavigationStack 与串流运行时实施。

| 范围 | 最终行为 |
| --- | --- |
| 共享页面与字体 | 18pt 分组标题、14pt 正文、12～13pt 辅助内容与工具动作；次级色形成可辨层级；滚动内容严格裁切在顶部以下。 |
| 我的、好友、成就、统计与相册 | 关键指标卡片化；统计明确“这些游戏”的口径；分页/缓存/已加载数量退出常态摘要；好友状态、成就状态、进度与媒体类型采用横条。 |
| 云游戏目录与游戏详情 | 正常页面聚焦游戏内容；更透的背景、圆角方形封面、可识别的个人资料入口、简介内的轻量操作、独立发行/特性卡片；游玩栏展示真实等待或访问要求。 |
| 主机与安装库 | 保留主机状态/空间等实际事实；排序、设备筛选具有操作边界；更新时间与服务 notices 退出常态列表。 |
| 控制器与设置 | 连接信息与可用设备事实形成卡片；空设备隐藏冗余未知字段；输入记录以横向滚动条与下划线表达，沿现有十条历史上限；诊断信息保留在明确的诊断/测试分区。 |
| 错误与空态 | 默认呈现可理解的失败及重试入口；原始错误通过主动展开查看；首次加载、无结果和权限要求按真实状态展示。 |

## 边界与风险

- 历史摘要来自当前游戏集合，使用“这些游戏”等范围说明，保持统计真实。
- 数据加载、分页、过滤值、身份隔离、输入锁定及十条历史消费沿现有模型；文本和显示层调整具有独立回归。
- 顶部裁切兼顾宽窗侧栏、原生返回与悬浮底栏；文字和按钮至少保留 44pt 操作区域，长名称与英文沿横滚或换行。

## 全局设计原则与逐条追踪（接续复审）

| 原则 | 公共实现与覆盖 | 对应批注 |
| --- | --- | --- |
| P01 内容先行 | 正常页面展示游戏、玩家、设备事实；首次等待、失败与权限只展示影响用户动作的内容；刷新反馈归属刷新按钮。 | 成就页接口/分页状态、全页面复审 |
| P02 语义层级 | 页标题、分组标题、正文、辅助标签分别使用公共字号；指标数值领先，事实使用标签/值，导航含方向指示。 | 游戏详情层级、连接信息成组 |
| P03 工具胶囊 | 搜索撑满内容宽度；少量互斥条件直接切换；筛选与排序同行；搜索36pt、选择32pt视觉高度，44pt触屏目标；窄窗/英文/大字号沿横滚显露完整选项。 | 样板图三处高度/圆角/同行/撑满 |
| P04 信息卡片 | 独立事实/指标成组，同组只保留一个外表面；封面表达游戏身份；简介展开附着同组标题。 | 小封面、特性/发行两卡片、控制器卡片 |
| P05 连续画布 | 背景图经渐变透出，文字区保持对比；原生顶部使用不透明画布完整覆盖正文，根页/子页/侧栏共享装配。 | 背景透出、全局顶部遮挡 |
| P06 内容密度 | 成就摘要呈现全成就游戏数与成就点数；分页动作居中；手柄十条历史保持下划线上方横滚。 | 样板摘要/居中、输入记录 |
| P07 自适应 | Dynamic Type 保留真实缩放；大字号事实/指标单列，长文本完整换行，触屏与无障碍选中状态共享实际绑定。 | 全页面原则延伸 |
