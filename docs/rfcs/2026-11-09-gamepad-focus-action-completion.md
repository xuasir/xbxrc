## Background

审计确认保存 / 刷新临时禁用导致移焦，程序化原生 focus 同步进一步清空 pendingRecovery；7 处原生下拉框、云游戏搜索 / 串流文字及相册视频内部操作存在手柄交互缺口。实际 Vue 8 场景、独立恢复断言与源码覆盖已经建立对照证据。

## Goal

1. 保存、刷新及弹层提交期间保留当前导航位置，合并重复确认；用户主动移动后保持新位置。
2. 程序化原生 focus 同步保留恢复事务，手柄意图、Tab 和指针操作显式取消旧恢复。
3. 库内全部下拉框使用现有单选弹层，实现 A 打开、方向选择、A 提交、B 取消和来源恢复。
4. 搜索、串流文字与音量输入复用现有屏幕键盘，保持父表单草稿、B 取消和输入来源归属。
5. 相册视频提供可导航的进度、音量、静音及全屏入口，继续操作现有 HTMLVideoElement。
6. 全量检查业务交互声明与实际页面的几何可达性；不同宽高控件的对齐计算保持宽行开关可达。
7. 宽度不超过 600px 时，二级菜单与页面上下分栏；菜单水平滚动，隐藏底部悬浮提示面板并释放内容空间。

## Scope

- 共享 NavigationEngine / Focusable / 输入诊断，设置行、编辑器、刷新和异步操作按钮。
- 7 处 library 原生 select、共享选择控件、XCloud 搜索、StreamTextSheet / StreamAudioSheet。
- 相册视频的 UI 控件与 DOM 播放操作、必要的行为回归及真实 Vue 隔离验证。
- 本地 1420 前端服务装配完整 App / 路由的离线交互验证，以及现有几何算法的不同尺寸对齐修复。
- AppShellLayout、SettingSidebar 与 ShellActionHints 的 ≤600px 上下分栏、水平菜单及悬浮提示隐藏。
- 技术路线保持 Vue 3 + TypeScript、Tauri + Rust、公共 InputController 和现有几何寻路；串流协议、媒体调度与后端运行时继续沿用当前主线。

## Behavior Contract

- `disabled` 表示控件当前不可用；`busy` 表示操作进行中。busy 控件继续参与几何导航，通过 `aria-busy` 和既有进度反馈展示状态，A / click / 输入提交在操作完成前合并。
- `Focusable` 同步同一原生焦点时保留 pendingRecovery；指针按下、点击、Tab 与导航意图显式决定取消恢复。真实禁用 / 删除继续沿用已有有效性、邻近回退、Scope 和 focus sink 合同。
- 选择控件复用 SettingSingleSelectPopupSheet，每个入口使用稳定 ID 与独立 Scope；选项变化、页面停用、关闭与重开按当前控件生命周期处理。
- 输入复用 SettingInputControl / SettingKeyboardSheet。完成只回填草稿，父页面沿用原保存 / 发送流程；输入控件停用、关闭或真正禁用时关闭旧键盘。
- 视频操作通过现有 video 节点完成，进度和音量具有边界校验；全屏依照 DOM / WebKit 实际能力装配，异步结果按视频身份处理。
- 同页分类 A 确认保持当前已选主入口；显式恢复来源、肩键切页与 KeepAlive 返回继续采用原页面恢复合同。
- 超窄屏共用单列两行骨架，菜单水平滚动；状态提示保留辅助技术读取，悬浮面板测量高度归零，正文只为一级导航与安全间距避让。
