## Background

进入云游戏加载期间、详情回退和切其他菜单时应用响应变慢。真实详情 setup + KeepAlive 回放已确认四步触发 6 次目录查询、6 次详情查询及 3 次空商品查询。源码还确认了全量重复交付、横栏完整挂载、网格持续追加、搜索/成员扫描和共享 store 多次保存。

## Goal

失活页面查询归零，热返回复用当前目录；卡片与焦点候选按视口有界；目录交付按内容版本幂等并增量更新；目录保存合并；图片尺寸和卡片绘制保持有界。

## Scope

- Vue：云目录共享投影、目录/详情生命周期、索引和搜索、虚拟网格/横栏、图片档位与卡片视觉。
- 几何导航：窗口挂载准备、容器候选缓存、单轮祖先可见性缓存，复用既有方向/焦点/返回合同。
- Rust data：内容 revision、轻量目录状态及单商品摘要、scoped patch、优先资料补齐与合并持久化；共享 catalog flow 的预算与进度扩展。
- typed RPC/events、适用回归、production 前端模拟服务验证、文档与性能证据。
- 串流媒体、网络恢复与输入传输沿用当前主线，发行入口沿用当前配置。

## Decisions

1. 云详情复用单实例，所属商品身份只在活动路由期间同步；数据缓存与实例缓存分别设置边界。失活解除页面订阅与等待，并隔离迟到响应。
2. 云目录共享投影保留账户/区域/市场/语言 scope 和认证代次；活动视图订阅，失活保留浏览状态。热激活通过轻量状态校验，内容版本一致时复用对象与索引。
3. snapshot 与 patch 分工：cold/scope/revision 缺口读取快照，正常刷新交付至多 75 项商品变更批次和独立状态终态；内容 revision 与更新时间分别表达内容和时效。
4. 虚拟网格按行、横栏按项挂载视口及邻近窗口；当前焦点保留，跨窗口先挂载候选再执行原几何选择。LT/RT 和返回按 section/product/action 恢复。
5. 目录索引使用 Map/Set 与预归一化搜索字段，空查询复用排序；大目录索引和搜索采用有界时间片，输入值即时同步。
6. Rust 现有 cache owner 合并 base/overlay/status 持久化并使用有界串行阻塞任务；首屏资料可优先呈现，最终完成保持 durable 保存。成功刷新显式保存目标最多两次。
7. 官方图片档位在已确认的 CDN 缩放参数范围内按 CSS 尺寸与 DPR 选择，来源回退和原地址保留；卡片图标采用低绘制成本的半透明表面。
8. 目录权益、缓存 TTL、公开浏览、暂缺收藏、栏目顺序、来源降级、合法空结果和 scoped 刷新终态继续贯通。共享 Rust 字段保持兼容默认值。
