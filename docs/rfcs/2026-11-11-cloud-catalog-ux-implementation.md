## Background

现有云目录已具备基础列表、缓存与导航。源码和公开接口抽样确认最近顺序、刷新终态、资料时间、标题身份和资格提示需要贯通；完整商品、官方栏目与等待接口可服务详情与开玩决策。

## Goal

实现可靠目录、高效搜索、详情与再次游玩、官方发现和等待预估、浏览与启动准入分层、本地收藏与栏目记忆。

## Scope

- `xbox-webapi`：定向 cloud title、Cloud 输入配置与 waittime、完整商品请求合同。
- `xbox-cloud-catalog-flow`：有序栏目、权益未知、商品详情与来源质量。
- Tauri data：目录/详情缓存、账户偏好、刷新终态、查询去重与身份映射；持久化与策略按职责分文件。
- Vue：云目录查询状态、分类/排序/搜索、稳定浏览锚点、独立 `/xcloud/games/:productId` 详情、收藏和可见访问状态。
- typed RPC / events、回归、真实组件模拟服务验证、RFC 与 Report。

## Decisions

1. 六项按一个依赖链推进，各里程碑独立验证。现有工作区改动在其当前内容上吸收。
2. 保留 product / stream title / Xbox title 三身份；Cloud 输入配置从正确的 Xbox title 和 Cloud 访问范围取得。
3. 权益采用 allowed / denied / unknown；公开商品资料允许浏览，Play 按当前账户目录或定向标题查询确认。
4. 资料时间来自实际取得内容；合法空目录提交新快照；来源局部失败保留同账户范围的最近成功数据。
5. 目录先呈现可用缓存/首批公开资料，后台取得账户访问和栏目/剩余资料；刷新成功、失败、取消均具有 scoped 终态。
6. 独立详情路由以 product ID 为身份，固定游玩操作，按需补完整资料，复用成就、时长与相册入口。
7. 发现采用云专用 newest、popular、leaving；列表保持服务顺序。排队按稳定聚焦约 500ms 触发，60 秒缓存、去重、最多两路、失效范围检查与离开取消。
8. 页面使用 section + product 稳定节点；返回/清空搜索/刷新/缩放恢复商品锚点和已浏览窗口。搜索做 NFKC、多词 AND、名称优先和别名匹配，分类与排序本地计算。
9. 收藏与置顶按账户 product overlay 本地持久化；栏目偏好同范围保存，目录暂缺收藏保留可见信息。
10. 当前市场保持 US，当前中文目录语言沿既有 zh-TW；服务英文 fallback name 作为名称别名。语言支持的未知状态显式展示。
11. 根据用户追加要求，卡片主体进入详情，播放和收藏采用独立图标按钮；三个入口为兄弟节点，分别接入几何导航和无障碍标签。
12. 详情采用 Hero、清晰的标题与游玩操作、收藏/置顶工具栏、简介展开、截图查看器、语言表与个人游戏记录；资料局部失败保留目录信息与重试入口。
13. 搜索控件使用 `externalFocus` 将轮廓交给整条搜索栏，静态轮廓和共享焦点动画共用外层边界；输入编辑与导航合同继续复用现有控件。
14. 已成功加载的空目录在刷新期间保留搜索、收藏与焦点；新鲜目录与缓存降级使用不同状态文案。
