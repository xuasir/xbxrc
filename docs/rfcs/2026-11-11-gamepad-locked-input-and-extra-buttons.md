# Xbox 输出映射、图上录入与自动输入测试

## Status

- Current State: implemented / automated and browser validation complete / physical-device validation pending
- Owner: 主窗口，单窗口直接执行
- Last Updated: 2026-11-11
- Execution authorization: 用户明确授权“执行改造”，并追加 Xbox、图内录入、组合映射、统一来源及测试自动识别要求。

## Background

用户的键盘和接入手柄提供实体输入，标准 Xbox 布局表示游戏输出目标。手柄可能有标准布局、非标准原始按钮/轴、背键和厂商扩展键；用户可以调整来源排列，也可以同时按多个来源键触发一个 Xbox 动作。配置中原“布局”和“键盘模拟”采用相同的目标编辑方式，按来源分别存储配置。

本 RFC 采用执行期间的最终决策：确认图上的目标后直接录入，全部松开或轴回中后自动结束；测试与实时输入保持独立锁定子页，自动识别键盘及所有接入设备，随最近活动来源更新显示。

## Goal

2026-11-11 追加执行范围：图示组在内容区居中，左右标注朝向引线并保留等距留白；浮层使用高对比表面。左右摇杆独立 Y 反转。震动按左右握把、左右扳机四路调节与测试，Browser 后端按 actuator 的 trigger-rumble 能力传递四路。界面震动与串流菜单/诊断菜单触发组合统一放在设置通用，复用公共输入、几何导航及 Rust 配置存储。

- 唯一“输入映射”入口，Xbox 目标图、标题旁的活动来源小标与图内直接录入。
- 键盘、标准手柄、非标准手柄按来源保存；切换来源保留草稿，恢复默认只影响当前来源。
- 支持 Xbox/Home、背键、原始按钮、轴与 2–4 个实体键组合。组合全按时输出目标，组成键的单键输出被吸收；单独使用来源键继续采用其单键绑定。
- 开关显示下一步动作：已开启显示关闭，已关闭显示开启。
- 测试始终可进入，自动识别最近活动来源，显示映射后的 Xbox 按键值及左右摇杆位置；键盘测试可在无手柄、游戏输入来源设为手柄时执行。
- 锁定观察退出：Menu+View 同时长按 1 秒或 Ctrl+Shift+Esc。图内录入允许采集 Menu+View，取消由顶部操作与键盘出口完成。
- 键盘模拟开关位于外层手柄设置。映射页只在键盘来源时显示八个摇杆方向；手柄的四个摇杆轴直接传递。
- 实时输入只在检测到扩展按钮输入后展示对应名称和按下效果；返回按钮提供触屏/鼠标入口。
- 摇杆和震动浮层从选中位置下方展开；死区用 0–30%、1% 步进的百分比滑杆，左右独立 Y 反转。震动分别调节左右握把、左右扳机，标题右侧测试当前选中通道。
- 界面震动总开关、串流菜单与诊断菜单快捷键位于设置通用；快捷键分组放在应用更新上方，沿用公共分组与设置行样式。

## Scope and Boundaries

交付在 `main` 的 Browser GamepadBackend、公共 InputController、几何导航、Vue 3 + TypeScript 与 Tauri/Rust 配置存储内完成。串流传输继续接收既有标准逻辑态。Native WIP 在 `rust` 开发线按相同合同适配。

标准设备的 UI 导航沿用物理标准态，游戏采用保存的输出映射；非标准设备的导航通过同一设备映射生成标准投影。键盘与屏幕虚拟控件直接表达 Xbox 输出，分别经过公共归属与持键释放屏障。配置好的 Menu/View 游戏组合在串流中用于目标输出，测试出口读取来源上的标准 Menu/View 投影。

## Configuration Contract

`gamepad_game_controls.deviceMappings` 保存最多 64 个布局，每个布局最多 21 个目标（17 按钮 + 4 摇杆轴）。稳定布局标识包含后端、设备类型、mapping 和原始控件数量；连接期设备 ID 用于当前输入与会话身份。

```ts
interface DeviceMapping {
  layout: string
  bindings: (
    | { target: XboxButton; kind: 'buttons'; buttons: number[]; mode: 'all' | 'any' }
    | { target: XboxButton | XboxStickAxis; kind: 'axis'; axis: number; invert: boolean; range: 'signed' | 'positive' | 'full' }
  )[]
}
```

- 原始按钮来源 0–127，轴来源 0–63；同布局目标与相同组合去重。
- `all` 为 1–4 个同时按住来源；`any` 用于兼容旧单键与背键合并，最多保留 128 来源。
- 标准设备首轮编辑由旧 `buttons/extraButtons` 完整迁移。非标准设备的四个摇杆轴默认直通，按钮初始未绑定，用户逐目标标定。
- 单一占用来源按已有标准交换规则处理；全范围轴支持 -1→1 与反向的 1→-1 模拟输入。
- 键盘沿用 `bindings`，增添有界 `chords: { keys, control }[]`；每组 2–4 个键、最多 25 目标。TS 和 Rust 同步归一化来源、目标、去重与预算。
- `invertLeftY/invertRightY` 分别保存两侧 Y 反转。`vibration_channels` 保存四路强度，旧震动强度作为各路缺省值。
- `stream_menu_shortcuts` 保存 `menu/diagnostics` 两组 0–4 个标准 Xbox 输出按钮；串流菜单默认 Menu+View，诊断菜单默认未绑定。运行时按映射后的输出识别，完整释放前触发一次并吸收组成键输出。

## Interaction and Lifecycle

1. 编辑器显示 20px 标题，恢复默认与应用位于右上角。
2. Xbox 目标按钮热点与引线标注共享录入入口。八个摇杆方向热点用于键盘录入；手柄来源保留 17 个标准按钮目标，扩展键作为输入绑定来源。
3. 入口持键先释放。录入记录最大同时按住集合，全部松开后原子写草稿；轴超过运动阈值后等待回到初始静止位置。完成恢复来源目标焦点。
4. 百分比滑杆、左右 Y 反转与四路震动使用选中位置下方的紧凑浮层。图示组在内容区居中，左右标注朝向引线并留出相同空白；浮层使用不透明高对比表面。录入状态和取消操作占据固定位置。
5. 测试与连接页实时输入复用同一锁定页。公共键盘桥在观察会话中采集保存的键盘映射；UI 导航和串流保持中立。测试遍历所有设备原始活动与键盘活动，自动更新来源小标和 Xbox 输出图，原始扩展按键在首次输入后保留名称、数值与点按效果。触屏/鼠标返回直接结束观察。
6. 观察页允许设备接入、断开及来源变化；图内设备录入在设备或布局变更时结束。退出、切页、停用、卸载清理 capture、观察、计时器和触觉。
7. 输入交接对按钮、模拟扳机、轴及虚拟输入建立释放屏障；异步保存与焦点恢复按会话身份校验。草稿返回提供放弃确认。

- 标准旧配置迁移、同来源交换、独立背键、非标准索引 0/24/127、数字/模拟轴、反向轴、组合成立与释放。
- 键盘单键与组合、原图录入完成、方向热点、来源切换草稿保存、单来源恢复默认与保存重载。
- 自动测试识别键盘/标准/非标准设备，无设备键盘测试、独占中立输出、两个出口与焦点返回。
- 原始模拟持键、配置变更、串流交接、断开、后台、停用与卸载。
