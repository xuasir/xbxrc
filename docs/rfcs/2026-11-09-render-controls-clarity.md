## Background

设置页的画面预设把锐度与颜色绑定，串流页的 SR 开关放在诊断菜单。串流页的两类修改都会写入全局配置；运行时的后端 SR 偏好又能覆盖本次关闭操作。用户因此难以判断所选模式、锐化力度和实际回退状态。

[最新实机分析](../../dev-docs/validation/2026-11-09-sr-sharpen-fresh-trace-analysis.md)显示 Video 常规段约 59.945fps，独立锐化与 SR 存在持续提交缺口。明确控制与运行事实便于用户选择，也能为接续性能对照提供稳定的模式边界。

## Goal

1. SR、独立锐化、Video 形成一个有效模式；SR 与独立锐化开关互斥。
2. 锐化提供“关闭 / 清晰 / 柔和”，关闭时保留原锐化选择的参数。
3. 设置页管理全局默认；串流页默认只调整本次会话，并提供显式保存默认与恢复默认操作。
4. 可开关的顶部指标栏用最简文本显示已提交的实际模式和回退原因。

## Scope

覆盖 Rust 配置兼容及领域映射、Vue 共用画面控件、当前会话覆盖、Browser renderer 选择与已提交状态事件、顶部指标栏和 SR A/B 临时调整。实际控件验证同时补齐滚动区纵向几何导航和 Scope 默认焦点的注册时序。保持现有媒体、帧源、几何导航、上屏调度和网络恢复路线。持续帧率优化与真实设备长测接续原任务。

## Control Contract

| 控件 | 用户操作与结果 |
| --- | --- |
| SR（实验性） | 开启选择 SR 并关闭独立锐化；关闭 SR 选择 Video。SR 自带细节增强，使用现有 SR 参数。 |
| 独立锐化 | 关闭、清晰、柔和三选一；选择清晰或柔和关闭 SR。锐化模式下关闭恢复默认渲染；SR 模式下该项保持关闭。 |
| 锐化参数 | 清晰沿用锐度 3（60%），柔和使用锐度 1（20%），用户界面使用三档名称。 |
| Video | 界面统一显示“默认渲染”，提供直接选择操作；SR 与独立锐化均关闭。 |
| 颜色预设 | 标准、鲜明、柔和仅调整饱和度、对比度、亮度，模式和锐化力度独立保留。 |

锐化沿当前 `sharpness / 5` 与百分比强度投影执行。Video 保持 CSS 颜色调整，独立锐化执行值为 0。颜色变化沿已选择模式执行。

两个入口共用画面设置组件。设置主行显示“默认渲染”“锐化 · 清晰 / 柔和”“SR”，SR 开关统一进入普通画面设置；诊断菜单保留 SR A/B 导出。色彩风格独立使用标准、鲜明、柔和。

## Configuration Ownership

持久化 `render_mode = video | sharpen | sr` 为模式权威，`display_options.sharpness` 保存记忆力度。旧 `super_resolution_experimental` 只承担兼容映射。

有效顺序为：未提交预览 > 有代际保护的 A/B 临时覆盖 > 本次会话覆盖 > 本次启动的全局默认快照 > 应用默认。显式 Video 与关闭操作拥有完整覆盖效力。

- 设置页：“保存默认”，下次新串流生效。
- 串流页：“应用本次”，默认只更新本次；“保存为默认并应用”显式写入全局；“恢复默认”恢复本次启动的默认快照并清除本次覆盖。
- 取消画面设置恢复已应用配置；重试、恢复与重连保留本次已应用配置；退出清理本次与临时覆盖。
- 保存失败保留编辑内容并显示错误；旧异步结果按执行与编辑代际吸收。

## Actual Rendering and Fallback

复用 PlaybackService 已提交 renderer 资源事件，将数值事实通过现有 runtime 事件通道交给页面。普通状态读取该事实；候选准备期间沿当前已提交模式显示，并附短暂“切换中”。启动尚无已提交 renderer 时显示“准备中”。

顶部指标栏沿现有显示开关，增加一个紧凑单元：`SR`、`锐化 · 清晰 / 柔和`、`默认渲染`；自动回退示例为 `默认渲染 · 帧率保护`、`默认渲染 · 增强失败`、`默认渲染 · 设备限制`。完整故障与技术字段继续留在诊断和 trace。指标栏关闭时该文本随栏隐藏。

SR 或独立锐化技术失败、WebGL 能力不足、现有渲染健康保护均直接回退 Video，用户所选模式保持。保留现有有界试探；显式重新选择增强可按既有恢复机制重试。SR 技术失败的旧“普通 WebGL 锐化”回退改为 Video，符合互斥控制合同。

状态事件来自 renderer commit / update / release / failure；使用现有资源快照中的管线、力度、代际和 pending 事实。顶部状态沿事件更新，复用现有统计采样。

## Compatibility

按原始配置键存在性迁移：有效 `render_mode` 优先；旧 SR 为 true 选择 SR；其余旧锐度大于 0 选择独立锐化；其余选择 Video。旧锐度 1–2 归柔和（1），3–10 归清晰（3）；0 或缺失采用记忆值 3，模式仍根据原始关闭意图决定。新默认为 Video 与清晰记忆值。

Rust 配置归一化与领域映射保持模式权威；前端仅表达控件和当前会话显示意图。旧布尔读取从模式派生，避免多个独立开关竞争。全局保存用同一个配置 patch 提交模式、力度与颜色。

SR A/B 通过临时完整配置覆盖执行，恢复模式、力度、颜色和覆盖来源；恢复资格绑定执行与调整代际。临时对照沿本次状态运行，全局默认保持原值。
对照截图等待目标 renderer 完成交接，最长 6 秒；目标回退或超时显示模式不可用。截图标签读取已提交模式，增强截图保持实际 renderer 的捕获路径。
