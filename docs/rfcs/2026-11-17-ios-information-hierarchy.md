## Goal

以身份、主机或游戏图片建立上半部通顶背景，主标题、身份、关键指标和主动作具有清晰主次。内容型页面使用分区、指标网格和媒体集合；设置页继续使用设置控件合同。

## Scope 与页面审计

| 页面 | 当前问题 | 调整 |
| --- | --- | --- |
| 我的/账户 | 小头像和逐字段资料条目，入口占据首屏 | 通顶头像背景与身份区；分组社交指标；根页入口网格 |
| 已安装游戏 | 主机/状态/更新时间分别卡片化，游戏列表出现在长表单之后 | 主机背景、状态与串流主动作；存储摘要合组；筛选紧凑并列；方形游戏网格 |
| 好友详情 | 身份与动作混入通用表单 | 头像通顶背景、玩家身份与当前游戏；最近游玩媒体集合 |
| 个人游戏概览与统计 | 封面/描述/日期/指标逐项列出 | 游戏背景与封面身份；简介、安装事实和统计分区，指标平铺 |
| 游玩/成就汇总 | 六项摘要逐字段卡片化 | 主指标与辅助指标网格，游戏集合使用封面卡片 |
| 好友列表/成就详情 | 更新时间、来源状态和说明被独立卡片化 | 普通内容分区；实际好友/成就项保持明确点击区域 |
| 云游戏/相册 | 已采用封面、媒体网格及平铺信息 | 沿现有媒体结构，云详情补通顶游戏背景 |

## Contracts

- 上部图片延伸至顶部安全区及原生工具栏，以主题渐变遮罩保证深浅主题文字对比；装饰图片退出无障碍树和点击处理。
- 缺少个人主题图时采用现有头像，主机使用既有 Series X/S 图片；加载与失败采用既有主题及图形回退。
- 身份标题24pt、关键指标18～24pt、正文14pt、辅助12～13pt，沿 appFont / Dynamic Type 和现有主题令牌。
- 窄屏和辅助字号采用单列；常规手机媒体/入口两列，宽窗按真实可用宽度扩展。导航归属、数据 owner、分页/筛选/返回与原桥接合同保持。
- 原生 NavigationStack、五图标悬浮底栏与实际左右宽度继续复用。触屏动作至少44pt。

## Validation

- 原有 PC 页面 UI 回归：安装库筛选返回、游戏四分区、好友成就、云截图与收藏、中英文统计和宽屏切换。
- 手机与 iPad 深浅主题、窄屏/大字号/横屏的内容截图；验证图片顶边、主动作、信息分组、末行可达和无键盘设置。
- Swift 格式、pnpm lint:fix、设备构建、streaming boundary 和 diff 检查。
