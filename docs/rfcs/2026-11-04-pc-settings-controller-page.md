# PC 设置层次、手柄页面与窗口布局修正

## Status

- Current State: completed
- Owner: 主窗口，单窗口执行
- Last Updated: 2026-11-04
- 执行授权：用户明确要求修正六项界面问题，包含独立手柄页面、手柄设置迁移和窗口顶部布局；按此具体范围直接执行。

## Goal

补齐分段选项常态底色，形成清晰的设置文字层次与紧凑更新卡片；将手柄设备和全部输入偏好集中于独立页面；提供图标刷新入口与独立系统标题栏。

## Decisions

- 延续已确认的方正小圆角、通顶环境光、中性哑光选中与透明分类标题。分段单选常态使用独立底色，行开关关闭态提供轨道底色。
- 设置分组标题、选项标题、说明和生效提示分别使用字号 / 字重 / 颜色层次；聚焦保留说明层次。
- 更新版本、通道、状态和动作聚合在独立轻底卡片中；现有检查、下载、切换确认与重启流程沿用。
- 增加 shell 路由 `/controller`，沿用 `top-nav.controller` 节点；一级页面顺序为主机、云游戏、设置、手柄，LB/RB 与触摸切换共用顺序。设置保留四类，手柄配置与设备选择迁至手柄页。
- 手柄页复用原有 InputController、配置保存与输入编辑会话，设备列表内联；键位 / 摇杆 / 键盘等编辑继续使用现有 FocusScope 和表单弹层，页面离开时统一释放捕获与草稿会话。
- 主机页刷新使用 36px 图标按钮，保留可访问名称、加载状态和原刷新动作。
- Tauri 主窗口标题栏使用 Visible，系统窗口按钮占用独立标题栏；前端取消 Overlay 专用左侧避让。原生窗口、认证及全屏继续由原壳层管理。
- Vue + TypeScript、Tauri + Rust、配置 schema、认证、串流、媒体及几何导航主线保持现有合同。
- 键盘映射保存时逐项构造 DTO，处理录入筛选后产生的嵌套响应式代理；主要按钮悬停保留品牌底色与文字对比。
