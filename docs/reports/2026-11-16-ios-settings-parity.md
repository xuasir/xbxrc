## 最终行为

- 通用、串流、连接、诊断、关于与控制器工具沿公共 AppSettingsForm / NavigationStack 装配。分辨率、H.264 档位、视频及音频上限、固定比例、颜色与锐化、四路震动、完整游戏语言和 TURN 均有实际消费者。
- 手机和平板均提供云/主机 1440/1081/1080/720、18:9/21:9 等完整选项；视频和音频手动上限均为 0～200，0 使用自动协商。自动模式保留手动保存值。
- 控制器图片选择映射目标、摇杆或震动部位；实体 A 在当前页开始录入，释放激活键后采样，目标组合释放或摇杆回中后自动保存退出。快捷操作录入与串流判定共用映射后的 Xbox 状态，附加背键和非居中轴沿同一物理采样工作。
- 选择、开关、动作和导航整行响应，图片热点至少 44pt。顶部画布遮挡滚动内容，固定底栏独占高度，中部滚动按真实可用高度裁剪；切换一级菜单恢复原生返回栈。
- 设置通过触屏、选择、滑杆、步进、文件或系统粘贴操作。中英动态组合、无障碍标签和值同步；长按默认显示中文 0.60 秒、英文 0.60 s。

## 消费与持久化

连接选项保持 AppSettingsStore → StreamingSessionSettingsSnapshot → UniFFI XboxStreamSettings → 共享 Rust compiler / plan → LibWebRtcRuntime 的原路径。IPv6 有候选排序消费者；音频上限有 SDP 投影；主机 TURN 默认关闭，自定义配置优先；服务器和游戏语言在下一次连接生效。

画面比例、颜色、锐化与设备原生 MetalFX 使用原有 StreamingMetalRenderer，沿同一纹理导入、mailbox、commandBuffer 与 present 工作。串流内可修改当前会话画面，恢复应用默认或保存为下一会话默认。紧凑性能浮层、音量控制显示、初始静音与常亮均接入真实会话行为。

控制器配置按设备布局保存，单键/轴交换、组合冲突、附加按钮、全范围轴、独立死区及反转都有回归。采样快照一次确定设备、标准状态和原始来源，并缓存布局键与归一化偏好。录入/测试/菜单/生命周期持有各自的抑制原因，恢复屏障同时检查原始与映射后按钮及摇杆。

连接设置继续使用 v1 持久化，移动偏好继续使用 v2 逐字段解码；缺失和坏字段独立回退，启动时归一化写回，保留旧用户值。TURN 凭据及内容保存在设备 Keychain，导入限 16 KiB，提供 URI/端口/transport/长度验证、预览和保存确认。

诊断沿同一 Trace writer，常规与轻量记录、手动录制、问题快照、最近记录、分享与清理均有消费。手动录制上限 5 分钟/32 MiB，最近 3 份保存 7 天；生产文件预算 8 MiB × 4，开发预算 32 MiB × 6，原有脱敏和队列压力保护继续作用。

## 平台差异

PC 防分辨率下降使用 RTP timestamp、receiveTime 和逐帧提交/解码/呈现时间形成反馈。当前 iOS SDK 公开 RTP 时间戳、解码帧交付和提交/呈现事件；逐帧接收及解码开始时间需要 SDK 提供。用户明确选择保留标准自适应并记录平台能力差异，设置页呈现标准自适应，现有 SDK 与标准 WebRTC 反馈持续运行。

iOS 采用 Apple 全屏、系统音量、场景后台生命周期和安装分发渠道。界面语言与外观提供跟随系统；桌面键盘录入由实体手柄、触屏、选择及系统粘贴完成对应移动任务。开发工具沿 Xcode 与原生 Trace 导出，超分沿同一媒体链的 MetalFX；真实硬件暴露的按钮、轴与触觉通道决定可用能力。

## 实机验收

1. 在真机分别连接 xCloud 和 xHome，切换分辨率、质量档位、自动/手动码率、游戏语言、服务器与 IPv6，确认下一连接的设置投影。TURN 导入后核对 Keychain 恢复及中继行为。
2. 连接实体手柄，按 A 录入标准键、背键与组合，释放后确认自动保存；切换设备、离开页面或进入后台，确认接管释放和回到 neutral 后恢复。按图片选择摇杆与四路震动，验证死区、反转及通道强度。
3. 串流内切换画面比例、颜色、锐化、MetalFX、静音、系统音量和紧凑统计；核对保存默认与会话内调整。使用 fresh trace 同时检查网络健康、恢复链健康、media supply、steady supply、submit/present 长尾和帧供给 delta，并记录真机观感、功耗与温度。

自动验证覆盖构建、合同、状态机与原生界面；真实账号串流、硬件触觉和 MetalFX 观感/性能按仓库约定由用户实机验收。
