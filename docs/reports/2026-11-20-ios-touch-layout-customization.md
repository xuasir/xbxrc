# iOS 触屏布局模板与可视化调整 Report

## Summary

2026-11-20。用户确认的 [RFC](../rfcs/2026-11-20-ios-touch-layout-customization.md) 已完成实施和自动验收。“控制器 → 触屏”成为模板选择、布局编辑和外观调整入口，本地串流与云游戏消费同一份已保存配置。[验收证据](../../dev-docs/validation/2026-11-20-ios-touch-layout-customization/README.md)已归档。

## Delivered

- 正式页面隐藏测试入口，增加通用 Xbox / 本地模板选择和两个原生导航子页。
- 自定义布局支持拖动、横竖屏独立位置、命名、保存、另存、恢复位置和删除；保存后自动选中，离开时丢弃未保存草稿。
- 当前模板的透明度和大小实时预览，范围分别为 20%～100% 和 75%～150%；外观随模板独立保存。

## Changes

- `TouchLayoutTemplate` 只保存稳定控件身份、位置和外观，动作与图标复用随包通用 Xbox。沿现有 MobilePreferences / AppSettingsStore 保存，保留旧 v2 字段默认值；旧测试布局、无效身份和损坏模板采用有效模板保留与标准布局回退。
- `TouchLayoutGeometry` 在基础 sockets 上应用位置、大小与安全边界，绘制、命中、无障碍范围及摇杆单位距离共用最终结果。竖屏所有控件保留在下半区，最小命中直径 44pt。
- `TouchLayoutSurface` 增加本地编辑模式；预览和草稿使用独立本地输入累加器。正式覆盖层读取当前模板，配置、方向、抑制、后台和关闭继续沿既有取消与释放路径。
- 内部布局测试保留 DEBUG 专用装配，中英文文案和 iOS 设计规范同步；技术栈、媒体与传输边界沿用现有合同。

## Validation

91 项 Swift 单元通过，包含 7 项新增模板持久化、异常数据、几何、命中和输入释放测试。iPhone 完成 5 个独立 UI 流程；iPad 的 2 项关键子页测试通过。最终 iPhoneOS 目标构建、Swift 格式、lint、工程与串流边界、diff 检查通过。

10 张最终截图、1 张定位诊断图及 10 个源码哈希已归档。验收期间的设备占用、事件合成与自动化定位失败已保留诊断，并由后续逐项通过结果收口。各轮来源见证据目录。

本轮 r1～r7 临时目录已清理，原占用约 1.52 GiB，磁盘可用空间净增约 1.53 GiB。共享依赖与编译缓存保留。

## Risks

自动验收覆盖组件、几何、存储与界面流程；真实设备触控手感、同时按键和外接手柄共同输入仍按仓库约定由用户实机核验。本地模板随当前设备的应用设置保存。

## Follow-up

使用包含本轮改动的 iOS 构建，在本地串流和云游戏中各切换一个模板，确认透明度、大小及横竖屏操作手感。
