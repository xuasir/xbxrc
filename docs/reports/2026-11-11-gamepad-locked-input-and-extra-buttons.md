## Delivered

- 布局、摇杆、键盘、震动、输入测试、高级和实时输入采用 `/controller/:tool` 完整子页；共享页面返回、滚动、几何 Scope 和层级过渡。标题使用 20px 公共字号，恢复默认与应用位于右上角，移除底部操作栏和分隔线。
- Xbox Series 正面图片两侧及上方居中 Xbox 标注使用原按键徽标、细连接线、箭头与映射名称。改动和实时按下持续高亮，映射目标在页内选择；窄窗口使用上图、下方两列标注，Xbox 独占一行。
- 图上实际按钮与标注共享编辑入口和高亮：桌面在图示下沿展开配置，窄窗口在选中标注之后展开。映射选择后即时更新名称并恢复来源焦点；背键使用同一编辑区，窄窗口按两列等宽排列。
- 点选摇杆直接调整死区预设、1% 精度和右摇杆 Y 反转，图上显示死区与位置点；键盘的摇杆按下/四方向绑定融合到对应摇杆入口；点选握把直接配置强度、游戏/界面震动和单侧测试。录入和实时输入图显示实际按键值。
- 录入成功后持续独占，Menu+View 同时长按 1 秒退出，Ctrl+Shift+Esc 为键盘出口。B、普通 Esc、肩键、扳机、单独 Menu/View 和背键保持可观察；出口显示进度。
- 标准布局的独立扩展按钮从索引 17 起采集，按设备布局保存并映射标准数字动作。多个来源按最大值合并，标准按钮双射与模拟扳机规则沿用原有合同。

- Xbox（Home）支持标准数字按钮双向交换、锁定采集、背键映射目标与键盘绑定；17 个图示入口包含 Xbox，保存重载与来源焦点完整恢复。

## Changes

- Browser 后端保留最多 128 按钮/64 轴，发布原始变化和稳定布局标识；公共控制器统一原始观察、扩展映射与持键释放屏障。
- Rust 配置默认值和归一化与 TS 解析对齐：128 条扩展绑定预算、17–127 来源索引、数字目标与布局隔离。旧配置的扩展集合为空，Home 的标准双射与扩展目标同步开放。物理 Home 经过公共游戏映射，串流菜单软 Home 保持逻辑 Home 命令。
- `GamepadToolPage`、`ControllerToolPage` 与 `SettingGamepadEditor` 承接子页编辑；设置列表与连接页保留明确工具入口。
- 草稿返回提供放弃确认，取消保留编辑；录入退出等待 DOM 与 FocusScope 注册后恢复来源按键，工具返回恢复入口焦点。直接打开测试页时提供无设备提示，激活手柄后进入锁定。
- 停用与卸载释放占用/计时器/触觉，迟到保存与焦点恢复校验会话身份；缓存工具页的键盘事件按活动状态保护。
- 工作区既有认证、诊断、视频配置与文案任务修改继续保留。

## 实机验收

- 在实际手柄上录入 Xbox 并与 A 交换，保存重载后在串流中确认实际 Home/A 输出和释放；采集以系统上报为准。
- 在实际手柄上录入 B，连续操作肩键/扳机/Menu/View，确认持续锁定及 Menu+View 长按出口。
- 用提供独立背键的设备录入并保存，重连后确认绑定恢复；串流中确认对应标准游戏动作、按下与释放。
- 在支持震动的设备上检查左右握把、强度与界面触觉，并检查断开/退出后停止震动。

背键独立性由固件、驱动和 Browser API 暴露决定；固件复用 A/B 等按键时展示对应标准输入。Native WIP 的扩展输入由 rust 开发线按同一合同继续适配。
