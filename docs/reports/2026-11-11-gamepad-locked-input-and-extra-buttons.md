## 最终功能

- “控制器 → 手柄设置 → 输入映射”统一配置键盘和接入手柄到标准 Xbox 输出的绑定。Xbox 图片表示 17 个标准按钮目标，包含 Xbox/Home；背键、厂商扩展键与非标准按钮作为来源录入。手柄四个摇杆轴默认直通，键盘来源显示八个摇杆方向入口。
- 点击图片热点或对应标注即可录入，记录最大同时按住集合；全部释放或轴回中后写入草稿、结束录入并恢复目标焦点。支持 2–4 个实体键同时触发一个 Xbox 输出，标准单键占用沿用交换规则。按来源保存草稿和配置，恢复默认作用于当前来源。
- 子页使用 20px 标题、右上角恢复默认与应用操作。录入状态和取消按钮占据固定位置。图示及标注在内容区居中，左侧文字朝向引线，左右引线保留相同空白。活动来源通过标题旁的小标自动更新。
- 输入测试和实时输入采用独立锁定子页，自动识别最近活动的键盘或接入设备，显示保存映射后的 Xbox 按键值与左右摇杆位置。键盘模拟关闭时仍可测试。扩展按钮在首次实际输入后显示名称、数值与按下效果，释放后保留已识别项目。
- 锁定测试期间 B 等普通按键用于输入观察。退出入口为同设备 Menu+View 长按 1 秒、Ctrl+Shift+Esc，以及触屏/鼠标返回按钮；安全出口保留在底部操作提示。设备断开后继续支持键盘观察。
- 摇杆与震动调节在选中位置下方展开宽度最多 264px 的高对比浮层。死区使用 0–30%、1% 步进百分比滑杆；左右摇杆各有独立 Y 反转，应用后保存。滑杆消费左右导航进行调节，上下导航继续公共几何寻路。
- 游戏震动分别配置左右握把、左右扳机四路强度，即时保存。标题右侧测试当前选中通道；Browser 后端根据 actuator 的 `trigger-rumble` 能力发送四路参数，双路设备的纯扳机测试返回能力不足并展示相应提示。
- “设置 → 通用”配置界面震动总开关和串流菜单、诊断菜单快捷键。快捷键分组位于应用更新上方，沿用公共分组标题与设置行样式；确认后录入 1–4 个标准 Xbox 输出按键或对应键盘绑定，全部松开自动保存，Esc 取消。串流菜单默认 Menu+View，诊断菜单默认未绑定。

## 配置与运行时

- 公共 InputController 继续负责 UI/串流归属、独占采集与释放屏障。Browser 后端保留最多 128 原始按钮和 64 轴，映射按稳定设备布局标识保存；非标准设备默认四轴直通、按钮未绑定。
- `gamepad_game_controls.deviceMappings` 支持按钮、按钮组合和模拟轴；键盘 `bindings/chords` 表达对应单键与组合。TS/Rust 对来源、目标、预算与去重进行同步归一化。
- 新增 `invertLeftY`、`vibration_channels` 和 `stream_menu_shortcuts` 配置。旧震动强度作为四路缺省值，两侧 Y 反转独立保存。
- 串流菜单快捷键按映射后的 Xbox 输出识别，每次完整按下/释放周期触发一次，组成键及其模拟扳机输出被吸收；菜单事件携带 `menu/diagnostics` 目标，串流页沿用现有诊断能力门禁。
- 停用、卸载、退出与来源交接清理 capture、键盘观察、计时器、持键和触觉。保存与焦点恢复按会话身份校验，草稿返回保留放弃确认。

## 实机验收

1. 使用实际键盘、标准和非标准手柄录入单键及组合，保存重连后在串流中确认 Xbox 输出、释放和两侧摇杆 Y 反转。
2. 使用提供独立背键的设备确认原始采集、绑定恢复和实际游戏输出。背键独立性由固件、驱动与 Browser API 上报决定；复用标准按钮的固件会表现为对应标准输入。
3. 使用支持四路马达的设备测试左右握把与左右扳机的独立强度，并在双路设备上确认能力提示；检查设备断开和退出后停止震动。
4. 在串流中确认菜单/诊断菜单快捷键的触发、组成键输出吸收，以及通用设置的界面震动开关。

主线保持 Tauri + Vue 3 + TypeScript + Rust、Browser 输入后端与公共几何导航。Native WIP 的扩展输入和触觉由 rust 开发线按同一合同适配。
