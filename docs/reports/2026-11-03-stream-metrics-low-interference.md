# 串流运行条与诊断指标改造 Report

## Summary

- Related RFC: [串流运行条与诊断指标改造](../rfcs/2026-11-03-stream-metrics-low-interference.md)
- 当前 `main` Browser 线路完成展示与交互改造，应用 XBX 设计体系。运行指标缩为顶部透明单行；诊断指标开启后直接进入分组详情。

## Delivered

- 顶部运行条保留实际源分辨率、呈现观察 FPS、视频 Mbps、RTT 和近 5 秒丢包；各密度保持五项，窄密度调整字号与间距，状态占用码率槽位。
- 诊断详情按网络、显示、恢复、会话四组组织，当前会话记住用户选择；固定不可用字段进入能力说明，可选缺值字段按有效数据显示。
- 详情采用 FocusScope / Focusable 与既有几何导航，支持切组、行焦点与滚动、关闭和复制指标快照。菜单到详情保持连续 UI 输入捕获，关闭及终止状态释放诊断捕获。

## Changes

- 展示投影明确源 / 输出尺寸、接收 / 解码 / 视频推进 / 渲染提交口径；有效零值正常显示，运行条过滤非有限值和负占位，过期数据使用空位及单一状态表达。
- 复用现有共享统计与 2 秒读取周期；读取失败清空当前快照并继续恢复读取。轮询代次吸收旧读取的迟到成功及失败结果，保护新快照。
- 新增 XBX 语义 tokens，运行条白字、直接吸顶、12% 实色黑底、点击穿透；诊断固定右侧三分之一宽、55% 实色表面、44px 操作和焦点环。2026-11-03 按用户实机反馈移除密度导致的隐藏字段和满宽规则。
- 中英文入口统一为运行指标 / 诊断指标；旧 `performance_style` 展示设置入口移除，底层配置保持读取兼容。

## Risks

浏览器 FPS 来自视频推进或渲染提交观测；GPU 耗时与实际屏幕 scanout 能力由显示组说明。新增展示使用现有统计窗口和平均耗时，真实串流与长测遵循用户手动验收约定。

## Follow-up

用户在真实串流中验收亮暗游戏画面、窗口化 / 全屏及窄窗口可读性，确认运行条与菜单避让，并检查手柄打开 / 切组 / 关闭后的输入归属和画面恢复状态。
