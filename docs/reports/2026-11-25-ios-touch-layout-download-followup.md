# iOS 布局下载与 Cloud / Home 切换 Report

## Summary

本轮修复全部游戏共用的来源身份、UTF-8 解析、单布局诊断隔离、查询缓存与失败重试，并接续两个详情下载入口和 Cloud / Home 串流选择。Cloud 查询当前游戏目录，点选后下载并切换；Home 切换本机保存布局，并提供标准／最近快捷。资源消费和输入沿既有 Rust 与 Swift 链路。

Related RFC：[游戏触屏布局保存与切换](../rfcs/2026-11-23-ios-saved-official-touch-layouts.md)。本报告收口请求与资源消费修复；原 RFC 的实际游戏包和 Home 实机验收继续跟踪。

## Delivered

- 社区按 Xbox 标题文件关联，商品元数据和当前游戏保存身份分别保留；普通游戏并行消费两种来源。
- TAKX 包内 UTF-8 文档按官方 trim 规则解析，兼容 BOM；缺失可选 Context 和单份损坏布局按实际使用情况提供诊断，资源预算与保存门禁有效。
- 成功目录按标题复用；重新查询刷新来源修订，失败和空目录支持重试，晚到旧请求保持缓存代次安全。官方及社区下载失败后均可重试并准备预览。
- 云游戏详情与主机已安装游戏详情共用官方／社区下载、预览和保存页，成功目录可重新查询。
- Cloud 当前游戏来自公共串流资格校验；选择器只查目录，点击才下载、校验和应用。下载成功后展示包内布局并复用当前会话缓存；默认项待适配时选择同包可用项。
- Cloud 和 Home 各自保留最近选择；Home 持久最近记录在 Cloud 会话期间保持有效。来源失败保留当前布局，游戏与会话代次变化使旧结果失效；布局提交共用触点释放和 neutral 输出。
- 横屏选择器目标高度提升到 320pt，随视口约束调整边界，列表滚动与点选覆盖 Cloud 当前游戏、Home 保存项和本地模板。

## Validation

R1 的 23 项布局 crate、15 项 iOS bridge、9 项 Swift 请求与消费回归、1 条 UI 冒烟全部通过并复用。微软提供的两个完整 TAKX 包包含七份带 BOM 的布局文档，验证默认布局、九份 2x 原始图片、预览、保存和重启加载。

R2 的 7 项单元和 3 条最终 UI 成功路径通过，覆盖两个下载入口的官方／社区操作、Cloud 按需下载与缓存、Home 保存布局与快捷、输入释放和旧请求失效。入口 UI 55.943 秒，最终 Cloud / Home 切换分别为 55.109 / 58.370 秒。

Home 初轮暴露横屏列表定位和浮层高度问题。滚动定位及共享高度修复后，仅补验受影响的 Cloud / Home 切换；已通过的单元和入口结果复用。初轮失败诊断、系统诊断收集停止记录与最终成功摘要均归档。

Rust 格式、Swift 本轮差异格式和 diff 检查通过。[证据与截图](../../dev-docs/validation/2026-11-25-ios-touch-layout-download-followup/README.md)记录原件来源、哈希、日志依据及单轮验证结果。

## Follow-up

用户失败游戏包的实际编码须由原件证实；当前用户日志已经确认 JSON 解析失败，微软原件已确认通用 BOM 兼容缺口。成功入口与串流 UI 采用可控请求客户端，解析和保存采用完整微软原件回归。实际账号服务、Cloud / Home 实机串流与手感使用新构建接续用户验收。
