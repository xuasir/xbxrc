# 串流菜单快捷键图示子页 Report

## Summary

“设置 → 串流体验”第一项现在打开串流菜单快捷键子页。子页使用当前页面背景，在左上和左下显示实际菜单按钮，提供图上录入和独立清空。

- Related RFC: [串流菜单快捷键图示子页](../rfcs/2026-11-12-stream-menu-shortcut-editor.md)
- Validation: [验证记录与截图](../../dev-docs/validation/2026-11-12-stream-menu-shortcut-editor/README.md)

## Delivered

- `/setting/stream-shortcuts` 复用手柄工具页页头、几何导航、状态和取消操作，返回串流体验时恢复配置入口焦点。
- 两个图标与串流页共用资产、32px 按钮和 24px 定位样式；绑定信息与清空按钮位于对应图标旁，内容区背景透明。
- 录入独占输入，支持 1–4 个标准 Xbox 输出或对应键盘绑定，全部释放后即时保存；B 和菜单组合参与正常录入。
- 两组快捷键可分别清空至 `[]`，允许同时未绑定；重复非空组合给出提示，写入失败保留配置，保存期间吸收重复确认。
- 退出、取消和卸载释放捕获，会话代次保护迟到保存的焦点；默认值为串流菜单 Menu + View、诊断菜单未绑定。

## Changes

设置展示 schema 和路由增加快捷键入口，通用页快捷键分组迁入独立编辑器。`GamepadToolPage` 增加可选页头及返回标签。真实串流页继续使用原有按钮逻辑，通过共用 CSS 维持位置、尺寸和显隐行为。

诊断 SVG 改为公共图标体系使用的主题着色描边，补齐浅色背景的可读性。配置保存仍使用 `stream_menu_shortcuts` 和公共 InputController，前端保持 Vue 3 + TypeScript，Rust 配置与输入后端合同继续复用。

- 离线页面完成 B 录入、诊断独立组合、两次独立清空、取消、恢复默认和往返焦点验证；控制台错误为 0。
- 默认窗口、800×600、390×844、320×844 测量均无横向溢出，中英文深浅色截图与主题图标验证完成。

## Risks

- 全仓 `pnpm lint:fix` 已执行；检查时有 8 项云目录及导航虚拟化并行修改的多语句格式错误，输出已保存在验证目录。本任务文件的定向检查通过。
- 额外设置合同测试的旧断言仍期望 `force_region_ip` 在下次连接生效，当前合同为下次授权生效；该差异由原任务继续处理。
- 真实手柄、原生壳层和远端串流菜单触发按仓库要求由用户手动验收。

## Follow-up

在桌面应用打开设置 → 串流体验 → 串流菜单快捷键，用真实手柄验证 B 录入、两个目标独立清空，并进入串流确认自定义菜单触发。
