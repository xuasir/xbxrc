# iOS 接收统计、色彩与音频校准交付

日期：2026-11-26。相关 [RFC](../rfcs/2026-11-26-ios-media-calibration.md) 与 [验收证据](../../dev-docs/validation/2026-11-26-ios-media-calibration/README.md)。本轮完成用户指定的三项修复及自动冒烟，长时稳定性接续后续任务。

## 交付行为

- 接收统计增加视频/音频 jitter-buffer 累计延迟、输出计数、目标/最低延迟，以及视频累计解码时间。每个 RTP 流独立保存基线，按窗口增量计算平均毫秒；首次、缺失、停供、流替换、计数回退保留未知状态。统计回调统一捕获单调时间，监督在异步依赖完成后捕获判定时间及连续事实快照。视频缓冲事实进入既有 Rust 3s/15s 窗口，诊断面板显示接收缓冲与单帧解码耗时。
- Metal 从 CVPixelBuffer 附件读取 YCbCr matrix、primaries 和 transfer，选择 BT.601 / BT.709 / BT.2020 SDR 矩阵和输出 colorspace。全范围/有限范围使用对应黑白点及 128/255 色度中心。缺少元数据时，SD 使用 BT.601，HD 使用 BT.709；矩阵、uniforms 与 layer colorspace 按配置变化缓存。CVPixelBuffer 零拷贝、Simulator I420 与既有 MetalFX 继续沿原管线。
- 音频生命周期保留立体声偏好与 Opus 声道声明观测，读取路由和实际设备参数。本地 PCM、首选采样率及 I/O 周期沿固定 M137 默认 ADM 的单声道 / 48kHz / 20ms 合同；健康路由由 SDK 处理设备格式，协商与路由更新诊断。保留 playAndRecord/voiceChat、默认扬声器和有效输入合同，生命周期继续处理初始激活、显式麦克风切换及系统恢复。

## 验证

一轮 iPhone 18 Pro / iOS 27.2 Simulator 的 14 项 XCTest 全部通过：9 项统计/色彩/音频校准、1 项跨异步快照的监督新鲜度回归、真实 Metal NV12 呈现、两种 WebRTC 工厂初始 offer，以及既有音频配置/权限边界。Rust 监督层 15 项通过，覆盖新增缓冲窗口和旧有 PC/原生基线。

新增三个模块通过 iPhoneOS SDK 的 Swift 6 严格并发及 warnings-as-errors 检查；12 个 Swift 文件按改动范围格式化，Rust cargo fmt、工程 plist、会话边界和 diff 检查通过。修复过的 CoreVideo Swift 导入诊断与结果导出权限诊断已保留，最终测试失败数为 0。

收尾时共享监督文件新增另一任务的可选恢复/延迟合同，三项 iOS 源码及本轮观察窗口保持已验版本。已保留双方改动、归档本轮共享源码快照，并追加 18 项共享兼容冒烟通过。


音频回归修正（2026-11-26）：用户后续反馈扬声器、麦克风关闭时撕裂/慢放/延迟。前轮双声道首选、5ms 缓冲及播放期重配置调参存在风险，初始化冒烟覆盖不足；已按固定 SDK 源码恢复默认格式，并移除健康路由/协商触发的配置重写，6 项原生音频回归通过。[回归证据](../../dev-docs/validation/2026-11-26-ios-audio-playout-regression/README.md)。

## 实机接续

固定 M137 ObjC receiver 公开只读接收参数，视频缓冲继续采用标准 libwebrtc 自动调节；新增窗口观测为实机低延迟校准提供依据。SDR 数值和原生呈现已验证，真实游戏颜色、系统路由声道、音质和端到端延迟按实际设备确认。

建议 Home / Cloud 各做一次短测，使用扬声器、有线耳机、蓝牙检查声音和路由切换，并留存接收缓冲/解码、网络 RTT/丢包、反馈/恢复、连续媒体供给、提交/上屏长尾与同窗帧 delta。
