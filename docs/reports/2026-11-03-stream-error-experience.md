# 串流错误体验 P0 / P1 / P2 Report

## Summary

- Related RFC: [串流错误体验](../rfcs/2026-11-03-stream-error-experience.md)
- 完成日期：2026-11-04。
- main Browser 串流完成错误分类、统一终态卡、等待提示及局部操作反馈。Vue 3 + TypeScript 负责页面体验，Tauri + Rust 公共合同和现有网络、媒体、恢复路径保持当前职责。

## Delivered

| 阶段 | 完成内容 |
| --- | --- |
| P0 | 保留结构化错误的类别、阶段、有界补偿与重试资格；Browser 原始代码先规范化再翻译；未知错误使用稳定正文。清理前固定安全字段快照，保留采样时刻、有效性、可用网络/帧率数据。 |
| P1 | 统一居中错误卡，按场景提供重新连接、重新登录、关机重试或返回列表；处理中/失败反馈、可折叠详情和复制结果完整。终态接管原面板；页面焦点域让位于弹层，主动作获得初始焦点。遮罩保持终态卡，B/Esc 先折叠详情，再执行返回。 |
| P2 | 首帧等待与播放停滞分别解释；被动状态条提供主动查看入口，沿用 60 秒期限。继续等待绑定当前停顿，真实新帧解除提示并重新武装。文本、显示、麦克风、截图、关机、全屏和超分分别提供局部失败反馈与再次操作入口。 |

## Changes

- `stream-errors.ts` 集中错误身份、标题/正文和白名单诊断投影；详情与复制共用失败快照，原始异常继续交给已有 trace。错误副本过滤账号、目标身份、地址、完整 URL 与协议内容。
- `useStreamExecution` 复用既有 single-flight、generation、取消和清理。清理 pending 保留原始失败，成功完成清理后才新建会话；退出期间的重试、旧登录请求和迟到关机结果遵循最新导航意图。
- `StreamAlertSheet` 沿用主题材质、圆角及现有 FocusScope/Focusable/几何导航，补齐主次动作、焦点环、窄窗口布局、详情滚动、Tab/Esc、dialog 语义与减少动态效果支持。
- 页面操作 owner 提供按操作 single-flight 和迟到回写隔离；文本与显示保存失败保留草稿，显示和超分的失败回滚受执行代次保护。麦克风按期望启用状态判断结果，正常关闭返回 false 作为成功处理。
- 截图导出错误卡纳入页面弹层输入所有者，关闭来源面板撤销迟到反馈；采集期间的超分调整在当前会话内还原。终态接管使局部错误失效。
- 关机请求失败与返回列表失败使用不同状态；串流结束后的局部失败保持可操作卡。结束、请求关机、返回期间显示处理进度，保留菜单返回入口。

## Risks

- 页面模拟覆盖交互与布局；真实鉴权、Xbox 云排队、主机控制、浏览器恢复与系统保存窗口的结果仍需实机验收。
- 错误详情只投影现有可用样本；缺样本与过期样本明确标注。网络健康、恢复链、media supply、steady supply、submit/present 长尾与帧供给 delta 的完整故障判断继续依赖现有 runtime trace 与诊断报告。
- Native WIP 的专属运行时验收归属 rust 开发线。

## Follow-up

建议实机按“启动失败/登录失效 → 连接中断/恢复 → 首帧与播放停滞 → 文本/显示/麦克风/导出/关机”顺序验收；核对物理手柄 A/B 持键出现弹窗、菜单切换、继续等待后的输入归属，以及亮暗游戏画面、窗口化/全屏的可读性。实机串流、长测与物理手柄沿仓库约定由用户手动执行。
