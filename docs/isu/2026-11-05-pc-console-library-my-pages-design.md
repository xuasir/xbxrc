# PC 主机游戏子页与“我的”四页设计

- 日期：2026-11-05
- 状态：设计方案；交付页面结构、交互合同与可切换示意。
- 用户方向：主机页增加对应主机的已安装游戏子页；一级菜单下组增加“我的”，承载账户与好友、成就、统计、相册四个子页。
- 最新布局约束：上组“主机 / 云游戏”，下组“我的 / 控制器 / 设置”；刷新使用图标；新增页面复用现有壳层、主题和左侧二级分类。
- 范围：PC 桌面端；Vue 3 + TypeScript / Tauri + Rust。移动端已有成就与个人数据作为复用依据。
- 关联分析：[Xbox WebAPI 能力扩展分析](2026-11-05-xbox-webapi-capability-expansion.md)。

## 问题界定

PC 端目前集中于主机串流、云游戏和设置。扩展后的信息架构需要让用户明确区分“这台主机装了什么”和“这个账户玩过什么”，并在同一游戏之间贯通成就、游玩数据和 Xbox 截图录像。

推荐采用一个稳定的主机子页和一个稳定的个人入口。主机游戏按设备组织，个人四页按账号组织；游戏身份承担跨页面联动，返回路径保留用户进入时的设备、筛选、滚动和焦点。

## 当前约束

### 产品与历史约束

- 现有壳层为顶栏、左侧分组导航、主内容、底部动作提示。左侧上组为“主机 / 云游戏”，下组按“我的 / 控制器 / 设置”排列。
- “我的”默认打开“账户与好友”，以现有 `SettingSidebar` 的左侧纵向分类切换页面，右侧承载对应内容。账户信息与好友列表共用第一子页，四页各自有独立路径和状态。
- 右上角头像保留轻量账户菜单，增加“进入我的”；资料、好友和游戏记录的完整阅读落在“我的”。退出登录沿用现有认证流程。
- 当前源码使用 2–8px 的小圆角、融合式导航、1:1 游戏封面。新页面直接沿用当前壳层尺寸、配色、材质、字体和语义 token；网格间距采用用户选定的 16px。
- 移动端轮播的内容字段、成就分组和排序经验可复用；PC 内容采用封面网格和紧凑列表，二级分类复用设置页与控制器页已有形式。
- 刷新入口复用 `Home.vue` 的 36px 图标控件：默认透明、小圆角、20px 图标，保留可访问名称和既有聚焦/禁用反馈。
- 主机串流继续使用现有 session 流程。查询主机的安装游戏、连接主机和指定游戏启动分别依照各自能力证据提供交互。

### 数据能力与缺口

| 页面 | 已有基础 | 设计依赖 |
| --- | --- | --- |
| 主机已安装游戏 | 主机列表、型号、电源、远程管理与串流，参考库安装列表/存储/状态查询 | Rust 增加三个 typed 查询，桌面 RPC/DTO 装配与真实主机覆盖率验证 |
| 账户与好友 | Profile；Rust 已查询 People 明细并提取数量；Social、Presence 有基础 | 保留人员明细、桌面好友 DTO、明确关系与在线状态语义 |
| 成就 | Rust TitleHub / Achievements 与 iOS 页面已交付 | 桌面 RPC、游戏汇总、详情与目标 XUID；各项进度保留服务语义 |
| 统计 | 历史、最近游玩、累计 MinutesPlayed、成就汇总 | 桌面装配、分页覆盖范围与缺值语义；周期趋势依赖持续快照 |
| 相册 | 参考库截图/录像 POST 查询、分页和媒体字段 | Rust Media 模块、双类型分页、地址失效刷新与预览/保存能力验证 |

## 推荐方向

### 信息架构

```text
主机
└─ 已安装游戏（当前主机）
   └─ 游戏详情：概览 / 成就 / 统计 / 相册
云游戏
我的
├─ 账户与好友
│  └─ 好友详情 → 游戏 → 成就对比
├─ 成就
│  └─ 游戏成就 → 成就详情
├─ 统计
│  └─ 单游戏统计
└─ 相册
   └─ 截图 / 录像预览
控制器
设置
```

“我的”直接打开内容；四个子页的首屏均包含右侧内容标题、页头刷新图标、局部刷新状态与可见内容。

### 主机 → 已安装游戏

主机首页保留重点主机和设备选择。在选中主机的操作区增加“已安装游戏”次按钮，主动作继续执行“开始串流”或既有唤醒连接流程。多设备选择改变次按钮的目标设备。

子页首行是“返回主机 / 客厅 Series X”，随后呈现主机名、型号、状态、“串流此主机”主按钮与刷新图标。设备身份固定在上下文中，切换设备由返回主机页完成。

容量区用紧凑横向信息展示各存储设备的已用与总量、剩余空间及采样时间。列表工具区提供游戏名称搜索、存储位置筛选，以及名称 / 最近使用 / 安装时间 / 占用空间排序；默认按最近使用排序，缺少时间的条目按名称稳定排在后方。

游戏网格采用 1:1 封面，每项显示名称、安装大小和存储位置。封面来源优先为已关联产品图，缺图时用标题占位。计数表达本次成功加载的游戏条目；安装应用、DLC 依据 `isGame / contentType / parentId` 归类，游戏数按已验证的顶层游戏口径计算。

点击游戏进入详情，展示简介、该主机上的安装事实，以及本人可见的成就、累计统计、相册。主动作“串流此主机”连接当前设备，用户随后在主机内选择游戏。指定游戏启动列为独立协议研究；远程安装、卸载和升级进度按未来明确合同扩展。

### 我的 → 账户与好友

顶部资料区控制在约 120–160px：头像、显示名、Gamertag、Gamerscore、本人在线状态及当前游戏。好友人数、关注数等标签按真实关系含义展示；数量缺值用明确的暂缺状态。

主体以好友列表为主要内容：头像、Gamertag、在线状态和正在玩的游戏。提供“全部 / 在线 / 游戏中”筛选和名称搜索，默认在线优先、游戏中靠前，再按 Gamertag 稳定排序。状态与游戏名同时提供文本，采样时间位于页头。

好友详情沿同一子页钻入，呈现可见个人资料和游戏历史。选择与本人相同的游戏后进入成就对比，以“我的 / 好友”两列表示已解锁、各自待完成和进度；同一成就按 SCID + 成就 ID 匹配。

首期社交动作集中于资料、历史和成就阅读。私密资料提供“该玩家的隐私设置限制了此项数据”，账号、好友状态与游戏记录分别呈现可读取部分。

### 我的 → 成就

首行展示 Gamerscore，游戏列表汇总限定为“已加载游戏”的成就进度。资料总分与历史页聚合分数保留各自标签和来源。

游戏网格显示完整方形封面、名称、已解锁 / 总数、已获得 / 总 Gamerscore、最近游玩或解锁时间。首版提供游戏搜索、“全部 / 进行中 / 已完成”筛选；默认最近游玩排序，汇总缺失的游戏单独表达状态。

进入游戏后，顶部为紧凑游戏信息和进度，下方为成就列表。成就展示图标、名称、描述、点数、服务返回的进度和解锁时间；提供“全部 / 待解锁 / 已解锁”和名称搜索。进度缺值时展示成就状态，复合要求以逐项要求表达。

秘密成就保留主动揭示入口，并以服务实际返回的描述为依据。本地追踪和稀有度按数据证据与持久化设计进入后续任务。好友成就对比从好友详情进入，与个人成就页共用详情结构。

### 我的 → 统计

首版提供“累计游玩”视图：已加载且有时长数据的游戏累计时长、已加载游戏数、已完成成就游戏数。每个值直接附覆盖范围；列表分页增长时同步更新聚合范围。

主体为按时长降序的游戏排行，同行显示方形缩略图、名称、累计时长和最后游玩时间。完成游戏作为相邻分区，按成就汇总事实定义“全成就”；每项能进入对应游戏详情。

缺少 MinutesPlayed 的游戏用“时长暂缺”，有数据的零值显示 0。精确值在单游戏详情以小时/分钟呈现；Hero 字段按游戏实际字段与单位显示。

周/月趋势列为第二阶段：启用账号作用域累计快照后，按采样区间计算增量，标明开始采样日期和采样缺口。首版用累计排行承载统计主体。

### 我的 → 相册

内容来自当前账号上传到 Xbox 网络的截图与录像。默认按时间浏览，工具区提供“全部 / 截图 / 录像”和游戏筛选。

采用统一 16:9 缩略图网格：截图显示游戏名和拍摄时间；录像增加时长与播放标记。打开后进入预览层，右侧/下方呈现游戏、时间、媒体类型和可用操作，关闭恢复原缩略图的焦点和滚动位置。

两类媒体分别保存 continuation 与加载状态，归一化后按时间合并；获取足够覆盖当前展示区间的两类数据后，再输出有序页面。“更多”继续取得两个来源后续范围，局部失败保留成功内容并显示对应类型的重试入口。

媒体地址依据 `expirationDate` 决定重新查询，预览与保存分别处理资源可用性。下载由用户主动触发，沿 Tauri 系统保存路径；外部分享以明确的系统/服务能力为依据。预览关闭或离开页面时停止视频与音频。

### 游戏关联与返回

游戏详情共用概览、成就、统计、相册结构，并记录来源页。设备安装事实使用 console identity，成就/时长使用 `xboxTitleId`，商品封面使用 `productId`，串流使用对应主机 `serverId`；关联字段缺失时保留可读取内容。

从主机详情跳到“我的 → 成就”，携带当前游戏选择；进入相册携带游戏过滤；从好友正在玩的游戏进入成就阅读时显式保留目标好友。返回恢复来源设备、筛选、滚动、焦点；返回后的异步刷新按当前账户与页面代际接收。

建议路径：`/xhome/:consoleKey/games`、`/xhome/:consoleKey/games/:installedItemKey`、`/my/account`、`/my/account/friends/:targetXuid`、`/my/achievements`、`/my/achievements/:xboxTitleId`、`/my/statistics`、`/my/album`。详情路由的一级高亮由 route meta 的所属页推导，`/my` 默认重定向到 `/my/account`。

### 手柄与窗口合同

- LB/RB：主机 → 云游戏 → 我的 → 控制器 → 设置；LT/RT：按现有机制切换当前页左侧分类。游戏详情的分类归属当前详情阅读层级。
- A 打开当前项，B/Esc 关闭预览或返回上一级；输入框沿现有编辑捕获机制消费文本按键。上下左右通过现有几何寻路引擎移动。
- 切页恢复该页最近聚焦项；刷新保留仍然存在的节点，条目删除后选择邻近有效项。预览/对比切入和退出使用现有 Scope 及焦点记忆。
- 常规窗口沿用“左侧分类 / 右侧内容”分栏，网格与对比根据现有内容区宽度排布；窄窗口按当前密度保留分类入口，工具区换行。正式验收包含 1280×720、960×540 及当前四档密度。
- 底部提示复用 ShellActionHints，按当前页动作显示，串流期间沿现有输入归属退出浏览刷新和媒体播放。

### 加载、刷新与空态

| 场景 | 页面行为 |
| --- | --- |
| 首次进入 | 仅加载当前页所需数据，显示对应骨架与结果范围 |
| 有缓存时刷新 | 保留内容、选项、滚动与焦点，页头显示更新时间和刷新进度 |
| 空安装列表/空好友/空相册 | 使用业务空态与刷新入口，说明主机、关系或 Xbox 上传范围 |
| 主机休眠或暂时离线 | 展示上次同步内容与时间，串流/唤醒动作依真实能力和状态提供 |
| 隐私限制 | 对受限资料或记录显示明确原因，保留其他可见区块 |
| 部分统计或详情查询失败 | 保留成功字段，局部重试；聚合值显示当前覆盖范围 |
| 登录过期与切换账号 | 沿现有认证恢复与账号隔离流程清理/恢复，迟到响应检查账号及请求代际 |
| 服务限流 | 遵循服务退避，提供下次刷新状态与局部重试 |

页面数据继续经共享 Rust API → 当前领域/宿主协调 → Tauri typed RPC → Vue 消费；缓存、持久化和请求取消延续现有模式。接口研究先用 fixture 与真实样本校准，页面再接入。
