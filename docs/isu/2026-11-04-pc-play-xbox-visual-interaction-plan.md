# PC 端 Play Xbox 新风格调整方案

日期：2026-11-04。状态：方案评审；已按通顶背景、融合式导航与信息区、方形完整封面修订。

## 问题界定

推荐采用 **首版整体布局、通顶环境光背景、左侧分组浮动导航、底部常驻提示区、右上角头像账户弹窗**。视觉以 `play.xbox.com` 新站为主，统一字体、色值、渐变、阴影、边框、圆角、间距和交互强度。导航与底部提示的默认状态融入页面，选中、悬停和聚焦时才出现材质反馈；云游戏沿用现有方形卡片和数据分组。

用户已选定深色、12px 卡片圆角、60% 环境光；浅色保留为适配主题。设置延续完整页面；账户信息由右上角头像展开弹窗。本轮交付调整方案与交互示意。前轮已完成主机透明图片及 Home 引用，应用壳层、卡片与账户菜单的正式改造列入后续实施。

### 新站的风格特点

- **背景通顶与局部环境光。** 顶部灰绿色径向光衰减至近黑背景，实际 DOM 为 `radial-gradient(44% 67.86% at 48.02% 0px, rgba(86,106,87,.70), rgba(61,115,64,0))`。
- **渐变形成材质厚度。** 导航组使用 165° 半透明深灰渐变、16px 外圆角、8px 按钮圆角与双层投影；当前页、悬停、焦点具有不同的反馈强度。
- **颜色集中于局部。** 青绿柔光、绿蓝边缘与深灰背板共同形成空间感，主按钮使用品牌绿。观察到的分类卡片为 2:3，属于新站分类入口；XBXRC 游戏封面继续遵循现有方形组件合同。
- **文字克制且动作明确。** 正文使用 Segoe 字体栈与常规字重；动作文字通过较高字重和主色获得识别。插画承担设备与状态的视觉表达。

实测导航组与分类卡片的 `backdrop-filter` 为 `none`。本方案的玻璃模糊属于 XBXRC 的适配参数，集中用于导航高亮、滚动后的粘性页头和弹窗。导航组、透明顶栏和底部提示区的默认状态均为透明。

## 推荐方向

### 1. 通顶背景与材质规范

背景由应用根容器统一绘制，贯穿产品顶栏、导航、主内容和底部提示。顶栏只承载标识、页面上下文、头像与窗口操作；标题栏区域延续同一背景。实施时检查 Tauri 标题栏与 WebView 顶部的绘制边界，按实际系统可拖拽区域布置控件。

导航组和底部提示默认透明，默认边框、阴影和模糊均为零。文字、图标和键帽维持必要对比。选中态增加深灰透明渐变与局部青绿柔光，悬停提高明度，聚焦增加单一外圈。主机重点区、设置面板与账户弹窗按内容语义承载材质，形成由背景至弹层的层级。

下表分别列出新站实测依据与 XBXRC 建议值。应用值为后续 token 的设计合同；最终颜色与合成成本需在真实 WebView 验收。

### 2. 壳层与底部提示

- 常规 PC 窗口保持第一版舒展布局：透明顶栏 52px、左侧约 72px 的分组导航、24～32px 内容间距。主机与云游戏在上组，设置与控制器在下组；导航名称始终可读，右上角头像独立承载账户。
- 左侧导航保持浮动位置与分组间距，组容器透明。高亮只落在当前或被操作的按钮上，形成明确的定位与聚焦反馈。
- 全部有效 A/B、LB/RB、LT/RT 与状态反馈集中于底部常驻提示区；提示区与主内容左边缘对齐，距底 14px，默认透明。单个键帽保留弱轮廓，底部整体视觉与背景融合。
- 提示区位于主内容滚动容器之外，布局采用 `52px / minmax(0,1fr) / 72px` 三段高度。主内容 `min-height:0`、独立滚动，滚动上下边缘保留焦点安全区。较矮窗口压缩内容重点区，底部提示持续可见。
- 弹窗期间底部显示确认 / 关闭；搜索态按当前能力收起 LT/RT 区域提示；设置显示分类切换。实际提示由既有输入归属与当前动作可用性驱动。
- 小尺寸适配保证全部入口可达；示意在内容宽度 700px 以下采用横向两组入口和可换行提示，作为窄窗口补充。正式应用沿当前四档密度确定最终断点。

1280×720 的应用内容高度预算为：52px 透明顶栏、596px 中间区、72px 底部提示与留白。验收使用实际 WebView content viewport，同时覆盖 1280×672 和 960×540。系统标题栏占用以真实窗口内容区为准。

### 3. 主机首页

恢复第一版“我的主机”标题、横向重点区、下方设备选择。常规重点区约 280px 高、32px 内边距，右侧主机图约 216px 高；紧凑窗口采用约 224px 高重点区与 176px 图片。名称、真实状态和主动作位于左侧，透明主机图与接触阴影位于右侧。多台主机在下方显示约 80～96px 高的选择区域，切换更新重点区并维持布局盒稳定。

动作继续消费真实能力：在线可串流显示“开始串流”；待机且支持远程管理使用对应唤醒连接动作；关闭与未知状态显示具体检查或刷新入口。初始选择沿用当前顺序，默认主机偏好作为独立产品事项。

已接入 `src/assets/console/series-x-transparent.png` 与 `series-s-transparent.png`：RGBA 512×512、主体高度 440px、四角透明。处理说明见 `src/assets/console/README.md`，`Home.vue` 已切换资源，型号选择与串流入口继续沿用。

### 4. 云游戏卡片与现有分组

最近游玩、新游戏、全部游戏和搜索结果统一使用 **1:1 方形卡片、完整图片、透明底色**。`tileImageUrl` 优先，缺少 tile 时使用 `posterImageUrl` 并保持原始比例；图像 `object-fit:contain`。留白区域直接透出页面背景，封面颜色来自游戏原图。

标题沿用原项目底部覆盖方式，使用局部透明至暗色渐变承载文字，保持图像边界与比例。默认卡片边框透明、投影为零；悬停使用细边与弱青绿柔光，聚焦使用统一签名外圈。原有密度尺寸与网格列数优先复用，最近与新游戏保持轨道语义，全部与搜索保持网格语义；示意中的静态网格用于查看共同的方形材质。

页头保留搜索、目录状态、更新时间、缓存刷新 / 重试与结果数。区块跳转只对应现有最近 / 新 / 全部，按页头实际高度避让粘性区域。页头初始透明；滚动后以局部半透明背板和模糊承载文字，底部渐隐融合页面。

搜索显示现有结果网格，清空后恢复分组与滚动位置；卡片确认直接进入既有串流流程。`miss/fresh/stale`、后台刷新、渐进加载、空结果和重试保持现有行为。轨道箭头、焦点滚动与几何引擎的快速导航共同验收。

示意已使用旧站官方 Cyberpunk 2077 与 NBA 方形封面，作为完整图片、方形比例和透明背板的验证样本。分组数据为示例，真实页面始终消费当前目录事实。

### 5. 交互强度与焦点

| 状态 | 统一反馈 |
| --- | --- |
| 默认导航 / 提示 / 游戏卡片 | 透明容器、稳定图像与可读标签 |
| 当前页 / 已选设备 | 弱渐变、局部柔光与选中语义 |
| 悬停 | 深灰渐变或细边，卡片上移约 1px；约 140ms |
| 聚焦 | 导航增加玻璃背板；控件统一单一焦点外圈，完整可见 |
| 按下 | 操作对象缩放约 0.985，反馈局部发生 |
| 账户 / 状态弹窗 | 锚定来源、较强玻璃材质、低透明度背景遮罩；关闭恢复来源 |
| 加载 / 刷新 | 缓存卡片与盒尺寸稳定，进度与重试局部呈现 |

页面转场建议轻微位移与淡入；滚动统一服从现有几何导航，组件自身 smooth / snap 与快速连续导航一起复核。减少动态效果偏好关闭装饰性运动。实体键盘输入、原生控件与弹窗焦点均纳入现有焦点合同。

### 6. 设置、账户与串流

设置使用 `/setting` 完整页面，保持通用、串流体验、连接与主机、手柄、高级与诊断五类，以及当前配置、输入、保存流程。分类与参数区分栏，按既有滚动和焦点安全区统一材质。

账户入口位于右上角头像；点击后在头像下方展开约 320px 宽资料弹窗，展示当前头像、名称、Gamertag、Gamerscore、登录状态与退出动作。资料缺失使用现有占位与状态。Tab 焦点限定于弹窗，B/Escape、关闭按钮与点击外部恢复头像焦点，取消退出恢复退出按钮；底部提示继续可见并切换为确认 / 关闭。

控制器状态继续使用小浮层并恢复来源。实际局部编辑与独占输入复用当前输入捕获机制。串流继续沿用低干扰 HUD 和既有诊断布局；浏览页面的环境光、图片更新和装饰停止消费串流期资源。
