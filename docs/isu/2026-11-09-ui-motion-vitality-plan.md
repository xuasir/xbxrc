# 应用动效与鲜活感方案

日期：2026-11-09，2026-11-10 修订。状态：三个正式实施阶段已落地，本地验证完成，实机验收待补齐。主窗口直接执行与验证；进度见[实施 RFC](../rfcs/2026-11-10-ui-motion-vitality.md)。

## 问题与目标

在当前紧凑布局、4 / 6 / 8 / 10px 圆角和绿青焦点色阶上，建立一套可长期使用的动态节奏。鲜活感主要来自操作之间的连续关系：切页有衔接，焦点有方向，背景有轻微环境变化；文字、数据、阅读区域保持稳定。

## 当前约束与证据

- Vue 3 + TypeScript 负责 UI；Tauri / Rust 和几何导航引擎沿用当前边界。
- [主路由](../../src/App.vue) 使用共享 WAAPI 并行过渡，280ms / 48px 按一级导航排列交接；[子页](../../src/pages/Controller.vue) 为 220ms / 24px，方向按菜单排列自适应，保留单根容器与即时滚动恢复。
- [焦点呈现](../../src/components/navigation/FocusFlowLayer.vue) 使用 2px 单例外环、4px 外扩；220ms 邻近飞行、100ms 跨区域淡入。渐变角度在短动画内累计并在停稳后静止，原有 CSS 外环保留为静止和能力缺失 fallback。按下与悬停位移作用于内部图像。
- [应用壳层](../../src/components/layout/AppShellLayout.vue) 已有静态顶部环境光。[最新密度验证](../../dev-docs/validation/2026-11-09-ui-focus-inset-density/README.md) 确认 8px 安全区、隐藏滚动条与重复提示、紧凑底栏和超窄屏上下分栏。
- [上一轮动效报告](../reports/2026-11-04-pc-controller-status-focus-motion.md) 约束单一焦点、来源恢复、稳定卡片高度与减少动态效果。
- 串流和录像播放优先保障媒体供帧，装饰动效按既有生命周期静止。

## 方向比较

| 方向 | 体验与成本 | 决策 |
| --- | --- | --- |
| 轻淡入 | 改动小，阅读很安静，空间联系较弱 | 作为减少动态效果模式的基础 |
| 页面短过渡、焦点柔光跟随、背景慢漂移 | 操作连贯，动态有主次，改动集中于共享视觉层 | 推荐，称为“轻流动” |
| 分层视差、弹簧缩放、逐卡片依次入场 | 视觉表达强，长时间浏览与连续手柄操作的动态负担较高 | 留作活动页和首次引导的独立用途 |

## 推荐方案：轻流动

### 直觉性总纲

2026-11-10 补充设计要求"动效设计要符合直觉"，操作化为五条准则：

1. 方向一致：一二级同层切页跟随可见菜单排列，桌面竖排上下交接、窄屏横排左右交接；前进自下 / 右进入，返回自上 / 左进入。LB/RB 保留前后页顺序，动效轴由当前布局决定；详情按水平层级进退，弹层保持垂直进入。
2. 因果连续：动效表达"发生了什么"。焦点环飞行表达同一个焦点移了过去；跨页面 / 弹层原位淡入表达在新位置重新聚焦，不伪装成移动。
3. 层级空间模型：同层页面按菜单排列交接，详情以水平推进 / 返回表达深度，弹层覆盖其上（遮罩先入、面板随后）。
4. 时长对等：页面 280ms / 48px、分类 220ms / 24px、邻近焦点 220ms 分档；同层进出等距、时长相同；弹层进入慢于退出（理解新状态 / 已做完决定）；确认与返回输入立即响应。
5. 物理自然：统一快速起步、缓慢收稳曲线，有质量感、不弹跳；停稳即静止。

总纲：每个动效必须能回答"它告诉了用户什么"，答不上来就删除。

### 页面与层级

| 场景 | 建议参数 | 行为 |
| --- | --- | --- |
| 一级页面切换 | 280ms；位移 48px，方向跟随主导航实际横竖排列 | 前进新页自下 / 右进入、旧页向上 / 左退出，返回方向反转；进出等距；无法判定方向的同层切换使用纯淡入；顶栏、导航与底栏位置稳定 |
| 二级分类切换 | 220ms；位移 24px，按菜单排列使用上下或左右交接 | 分类立即选中，参数区域整体过渡，行高与滚动位置稳定；返回按同一轴反向交接 |
| 详情进入 / 返回 | 280ms；水平位移 48px | 方向与进入、返回关系对应；来源页恢复已有焦点与滚动记忆 |
| 弹层 | 进入 180ms、退出 120ms；位移 6px | 遮罩先淡入，面板随后稳定，关闭后立即恢复来源焦点 |
| 首次内容到达 | 最多三个内容组错开 20ms；总长 ≤240ms | 标题、主体、列表形成轻微层次；缓存刷新采用局部更新 |

页面与焦点飞行使用 cubic-bezier(0.25, 0.6, 0.3, 1)，让交接过程更清晰、收稳更舒展；弹层使用 cubic-bezier(0.2, 0.75, 0.25, 1)。快切以最新页面为目标，中途输入可结束当前视觉过渡。新页面成为唯一交互页面；离开画面仅用于短暂视觉过渡，交互与导航候选按当前 Scope 合同释放。通过真实 Vue 验证 KeepAlive、单根节点、滚动恢复和快速往返后确定装配方式。

视口边缘目标、缓存恢复和滚动期间优先使用纯淡入；8px 焦点安全区继续作为布局下限。页面动画的视觉位置与命中框分离，输入发生时按稳定几何位置计算导航。

### 焦点流动

2026-11-10 修订：确认采用"环整体飞行"档——全局单例 FocusFlowLayer 承载 2px 流动外环，同一可见区域的邻近目标切换时，外环以 220ms 飞行移动到新目标（宽高、圆角同步过渡）；跨页面、跨弹层、FocusScope 切换与长距离跳转使用约 100ms 原位淡入；滚动进行中即时吸附当前目标；快速连续输入只保留最新目标，允许飞行中途重定向。低亮度柔光降级为可选增强，默认关闭。焦点停稳后外环保持静止。

焦点逻辑继续由 navigationEngine 决定。视觉层消费已有 onFocusChange 和 getCurrentFocus，订阅随视图释放；FocusFlowLayer 保持 pointer-events: none。环本体沿用 conic-gradient + mask 描边，尺寸与位置经 Web Animations API 过渡 left / top / width / height，避免 transform: scale 拉粗 2px 边框；conic 流动角度置于全局层，飞行中角度连续不重播。base.css 现有每元素 ::before 环降级为 reduced-motion 与 JS 层未就绪时的 fallback。唯一明亮外环表达当前可操作目标。

连续方向输入只保留最新位置，确认按当前逻辑焦点立即执行；busy、A 去重、FocusScope 和来源恢复沿用已有合同。卡片的图像或内部内容可轻提 1px；按下反馈在内部内容缩至 0.99、约 80ms，释放约 120ms。交互元素的导航边界保持稳定。

### 背景流动

壳层保留现有静态底色与顶部环境光，增加一层低频、低对比的绿青光场。建议 36 秒一个完整往返，横向总漂移 24px、纵向 12px，亮度变化约 5%；浅色主题进一步降低色层强度。

环境光方向保持稳定，页面切换延续同一周期。常态下仅背景承担持续装饰运动；控件停稳后静止。渐变图像预先保持静态，整体通过 transform / opacity 变化；合成成本在实际 WebView 验证后确认。

### 动态优先级

1. 确认、返回、输入与逻辑焦点立即响应。
2. 焦点、页面和弹层承担短时反馈，允许输入中断。
3. 背景承担慢速环境变化，优先让出资源。

应用前台浏览时使用完整方案；窗口失焦、页面隐藏、串流准备 / 播放、录像播放及减少动态效果偏好下进入静止状态。减少动态效果保留即时焦点、选择、加载状态和清晰的页面变化。

文字与列表静止，状态变化采用一次短暂亮度反馈。动画参数集中到现有主题 token，共享页面过渡和焦点呈现；触屏、鼠标、键盘、手柄的操作节奏共用。

- 2026-11-10：结合当前代码核对四项诉求并确认方向。焦点环液态流动（base.css conic 流动）与页面切换（page-fade 220ms）已在 main 上线；SettingConfirmSheet 无过渡、背景仍为静态环境光，为剩余缺口。用户确认焦点切换采用"环整体飞行"档（全局 FocusFlowLayer + 分段策略：邻近飞行 / 跨页原位淡入 / 滚动吸附 / 连按重定向），柔光降为可选增强；补齐飞行层技术要点（WAAPI 尺寸过渡保持 2px 均匀边框、conic 角度全局连续、既有 ::before 环降级为 fallback）与验证问题。第二阶段任务更新为焦点环整体飞行层。
