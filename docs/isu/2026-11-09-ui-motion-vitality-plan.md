# 应用动效与鲜活感方案

日期：2026-11-09。状态：方案与示意完成，后续实施待排期。主窗口直接设计与验证。

## 问题与目标

在当前紧凑布局、4 / 6 / 8 / 10px 圆角和绿青焦点色阶上，建立一套可长期使用的动态节奏。鲜活感主要来自操作之间的连续关系：切页有衔接，焦点有方向，背景有轻微环境变化；文字、数据、阅读区域保持稳定。

## 当前约束与证据

- Vue 3 + TypeScript 负责 UI；Tauri / Rust 和几何导航引擎沿用当前边界。
- [主路由](../../src/App.vue) 的进入、离开分别使用 220ms 过渡，out-in 顺序执行两段；[子页](../../src/pages/Controller.vue) 为 160ms。现有子页已补齐单根容器及滚动恢复。
- [焦点样式](../../src/styles/base.css) 采用 2px 外环、4px 外扩和 8 秒循环渐变。当前全控件焦点进入还会缩放实际交互元素。
- [应用壳层](../../src/components/layout/AppShellLayout.vue) 已有静态顶部环境光。[最新密度验证](../../dev-docs/validation/2026-11-09-ui-focus-inset-density/README.md) 确认 8px 安全区、隐藏滚动条与重复提示、紧凑底栏和超窄屏上下分栏。
- [上一轮动效报告](../reports/2026-11-04-pc-controller-status-focus-motion.md) 约束单一焦点、来源恢复、稳定卡片高度与减少动态效果。
- 串流和录像播放优先保障媒体供帧，装饰动效按既有生命周期静止。

## 方向比较

| 方向 | 体验与成本 | 决策 |
| --- | --- | --- |
| 轻淡入 | 改动小，阅读很安静，空间联系较弱 | 作为减少动态效果模式的基础 |
| 页面短过渡、焦点柔光跟随、背景慢漂移 | 操作连贯，动态有主次，改动集中于共享视觉层 | 推荐，称为“轻流动” |
| 分层视差、弹簧缩放、逐卡片依次入场 | 视觉表达强，长时间浏览与连续手柄操作的动态负担较高 | 留作活动页和首次引导的独立用途 |

## 推荐方案：轻流动

### 页面与层级

| 场景 | 建议参数 | 行为 |
| --- | --- | --- |
| 一级页面切换 | 总节奏目标 180–220ms；新页 200ms；位移 6px | 新内容及时呈现，旧画面短暂淡出，顶栏、导航与底栏位置稳定 |
| 二级分类切换 | 140–160ms；位移 4px | 分类立即选中，参数区域整体过渡，行高与滚动位置稳定 |
| 详情进入 / 返回 | 180ms；水平位移 8px | 方向与进入、返回关系对应；来源页恢复已有焦点与滚动记忆 |
| 弹层 | 进入 180ms、退出 120ms；位移 6px | 遮罩先淡入，面板随后稳定，关闭后立即恢复来源焦点 |
| 首次内容到达 | 最多三个内容组错开 20ms；总长 ≤240ms | 标题、主体、列表形成轻微层次；缓存刷新采用局部更新 |

默认使用快速起步、缓慢收稳的曲线，建议 cubic-bezier(0.2, 0.75, 0.25, 1)。快切以最新页面为目标，中途输入可结束当前视觉过渡。新页面成为唯一交互页面；离开画面仅用于短暂视觉过渡，交互与导航候选按当前 Scope 合同释放。通过真实 Vue 验证 KeepAlive、单根节点、滚动恢复和快速往返后确定装配方式。

视口边缘目标、缓存恢复和滚动期间优先使用纯淡入；8px 焦点安全区继续作为布局下限。页面动画的视觉位置与命中框分离，输入发生时按稳定几何位置计算导航。

### 焦点流动

主焦点外环立即出现在当前目标上，2px 细环和主题色阶保持清晰。低亮度柔光用 120–160ms 跟随同一可见区域的邻近目标；焦点停稳后轮廓与柔光保持静止。跨页面、跨弹层、长距离跳转和滚动重新定位采用约 100ms 的原位淡入。

焦点逻辑继续由 navigationEngine 决定。视觉层消费已有 onFocusChange 和 getCurrentFocus，订阅随视图释放；柔光层保持 pointer-events: none，目标尺寸立即更新，仅位置与透明度过渡。唯一明亮外环表达当前可操作目标。

连续方向输入只保留最新位置，确认按当前逻辑焦点立即执行；busy、A 去重、FocusScope 和来源恢复沿用已有合同。卡片的图像或内部内容可轻提 1px；按下反馈在内部内容缩至 0.99、约 80ms，释放约 120ms。交互元素的导航边界保持稳定。

### 背景流动

壳层保留现有静态底色与顶部环境光，增加一层低频、低对比的绿青光场。建议 36 秒一个完整往返，横向总漂移 24px、纵向 12px，亮度变化约 5%；浅色主题进一步降低色层强度。

环境光方向保持稳定，页面切换延续同一周期。常态下仅背景承担持续装饰运动；控件停稳后静止。渐变图像预先保持静态，整体通过 transform / opacity 变化；合成成本在实际 WebView 验证后确认。

### 动态优先级

1. 确认、返回、输入与逻辑焦点立即响应。
2. 焦点、页面和弹层承担短时反馈，允许输入中断。
3. 背景承担慢速环境变化，优先让出资源。

应用前台浏览时使用完整方案；窗口失焦、页面隐藏、串流准备 / 播放、录像播放及减少动态效果偏好下进入静止状态。减少动态效果保留即时焦点、选择、加载状态和清晰的页面变化。

文字与列表静止，状态变化采用一次短暂亮度反馈。动画参数集中到现有主题 token，共享页面过渡和焦点呈现；触屏、鼠标、键盘、手柄的操作节奏共用。

## 待验证问题

- 焦点柔光在嵌套滚动区、弹层和快速连按时的对齐，需要完整本地前端与已有焦点回归共同验证。
- 页面过渡并行呈现与 KeepAlive、busy 恢复、离开 Scope 的配合，需要真实 Vue 证明唯一交互页面及稳定来源恢复。
- WKWebView 在低功耗设备上的合成与媒体供帧成本需要实机取样；这里的数值属于设计目标。
- 后台暂停、串流进入与录像关闭后的恢复，应消费既有生命周期事实。

## 本轮验证结果

[验证记录](../../dev-docs/validation/2026-11-09-ui-motion-vitality/README.md)保存 21 项通过的检查和截图：

- 五页在实际 1248px / 320px 内容宽度下均保持唯一当前页面、完整焦点环和横向排布；浅色设置页另作窄屏核对。
- 邻近目标柔光使用 140ms 过渡，逻辑目标的 2px 外环即时出现，停止后中心偏差为 0px；连续切页回到主机页保持可操作目标。
- 弹层通过 inert 独占交互并暂停环境光，Esc / K 恢复来源按钮；减少动态效果将环境光动画置为 none、柔光过渡置为 0s，并保留清晰外环和确认 / 返回。

示意复查时补齐了视觉过渡中断后的柔光重新定位，以及减少动态效果偏好的展示同步。JavaScript 语法与静态 DOM 引用检查通过，浏览器运行错误为 0；临时浏览器页与 8949 预览服务已关闭。

验证覆盖独立示意的视觉与交互。Vue 路由 / KeepAlive / FocusScope、真实手柄、窗口生命周期和媒体供帧成本按上方问题进入正式实施验收。建议按页面与弹层、焦点柔光、慢背景的顺序落地，背景阶段以实机媒体供帧证据决定开启范围。
