# iOS 主机页视觉密度整改方案

## Problem Framing

- 当前主机页已经具备成就同构圆弧轮播、主机照片、长按电源菜单和串流入口，但页面仍由一张灰黑主机卡与一个按钮主导。
- 核心问题是视觉焦点、信息密度和 Liquid Glass 层级同时偏弱。主机照片缺少色彩环境与高光，卡片之外缺少可扫描的状态信息，剩余空间因此表现为空白。
- 整改目标是让用户第一眼看到“我的主机当前是否适合游玩”，随后快速读取主机状态与能力，并以一个明确主操作开始串流。

## Current Constraints

- 主机页继续复用成就页的 `OrbitCardCarousel`，卡片宽度与三行信息卡统一为页面宽度减 32pt，高度保持 390pt，并保留圆弧轨道、侧卡深度和拖动选择。
- 主机照片仍是卡片主体；名称、在线状态和可用空间继续位于卡片底部。
- 页面底部提供开始游玩与单一状态电源操作；长按当前卡片继续展示同一状态对应的电源菜单。
- 可用数据包括主机型号、电源状态、远程管理、主机串流、地区、语言和存储设备。
- 移动中的卡片不适合承载独立 `glassEffect` 合成层。已有实现证明，Glass 层与轮播旋转、缩放、位移分开合成时会产生视觉错位。
- Liquid Glass 集中在静态区域：三行信息区、两个操作按钮和必要的状态反馈。

## Options

### Option A：只增强主机卡

- 提亮主机照片，增加色彩环境、轮廓高光、渐变信息区和更强阴影。
- 优点：改动小，视觉焦点能够快速改善。
- 代价：下半屏仍然空旷，远程管理、串流能力等现有信息继续被隐藏。

### Option B：Hero 轮播 + 三行信息区 + 操作组

- 顶部保留主机 Hero 轮播；轮播下方增加三行 Liquid Glass 信息；下部放置开始游玩与单一状态电源按钮。
- 优点：视觉、信息与操作形成清晰层次，现有数据得到有效利用，下半屏拥有稳定内容，轮播运动与 Glass 合成边界清晰。
- 代价：纵向内容增加，小屏依赖自然滚动。

### Option C：完整主机控制台

- 将开机、关机、串流、存储、地区和远程能力全部展开为可操作面板。
- 优点：功能密度最高。
- 代价：页面从“选择并游玩”变成管理后台，视觉重心分散，长按电源交互失去意义。

## Recommended Direction

采用 Option B，并按最终示意图收敛为三个明确区域：

```text
┌─────────────────────┐
│ 主机照片 Hero        │
│                     │
│ 名称                 │
│ ● 在线   可用 124 GB │
└─────────────────────┘

╭─────────────────────╮
│ ▣ 主机型号  Series X  ›│
│ ◉ 远程管理    已开启  ›│
│ ▶ 主机串流    已开启  ›│
╰─────────────────────╯

        ( ▶ )       ( ⏻ )
```

### 1. Hero 卡片：建立第一眼落点

- 主机展示区使用页面宽度减 32pt 的自适应宽度与 390pt 高度，和下方三行信息卡左右对齐；共享轮播为主机页关闭圆角遮罩、描边与整卡阴影。
- 主机展示区采用完全透明的单一合成层，系统 Canvas 直接贯穿照片与基础信息区域，主机本体保持无遮挡的真实视觉。
- 主机照片提高亮度和局部对比度，使用轻微向上的位置偏移和阴影，让硬件主体在上部形成悬浮感。
- 卡片下部使用约 64pt 的透明零模糊信息区，直接共享整卡连续渐变；名称使用 `title3.bold`，状态与存储使用 `caption/subheadline`，照片区域保持完整视觉焦点。
- 底部信息条第一行并排展示主机名称与状态点，第二行展示可用空间；文字使用系统自适应前景色，在线为绿色、待机为琥珀色、离线为灰色。
- 多台主机时在轮播与状态仪表带之间显示紧凑分页点，选中点使用主题绿。
- 卡片边缘保留白色细描边与统一阴影，由 `OrbitCardCarousel` 一次性处理。

### 2. 三行信息区：补足信息密度与 Glass 质感

- 在当前卡片下方增加一个静态 Liquid Glass 容器，宽度为页面宽度减 32pt，圆角 18pt，内部使用三行信息。
- 三行固定为：
  - `主机型号`：Series X / Series S / 原始型号回退。
  - `远程管理`：已开启 / 已关闭 / 同步中。
  - `主机串流`：已开启 / 已关闭 / 同步中。
- 每行由 18pt 黑色图标、正文标题和右对齐状态值组成，行高约 58pt。
- 标题保持主文本色；状态色只用于值；信息行不显示箭头。
- 存储信息继续留在 Hero 卡片，三行信息区不重复显示。
- 三行信息随当前轮播选择更新，使用 220ms 淡入与轻微位移动画。

### 3. 状态操作区：形成明确动作终点

- 操作区水平居中放置两个 62pt 圆形 Liquid Glass 图标按钮，不显示文字说明。
- 开始游玩始终保留；电源操作同一时刻只显示一个：开机状态显示关机，关机、待机或已连接状态显示开机。
- 两个按钮使用极低强度 tint，禁用态降低 tint 与图标强度。
- 长按当前卡片继续进入跟随卡片的 `confirmationDialog`，保留快捷电源菜单。

### 4. 页面节奏

- 顶部直接进入 Hero，保留 12pt 安全呼吸空间。
- Hero 与三行信息区保留约 20pt 间距；状态操作区通过上下等量弹性空间吸收大屏剩余高度。
- 页面内容以可用高度为最小高度；两个操作按钮在信息区下方的剩余区域内垂直居中。
- 小屏允许纵向滚动，操作区通过底部 safe-area padding 与 Tab Bar 保持稳定间距。

### 5. 色彩与材质

- 页面背景继续使用现有绿/冷色自适应 Canvas。
- Hero 卡片增加两种环境色，避免全页只剩黑白灰；品牌绿继续只承担在线状态和主操作。
- Liquid Glass 用于静态三行信息区与两个圆形操作按钮。Hero 使用无背景透明排布，层次由主机照片自身的轻阴影承担；下部信息区作为完全透明的内容层并保持零模糊。
- 状态图标可引入绿色、琥珀色和冷灰色；其余文字维持主/次/三级信息色。

## Open Questions

- 非 Series X/S 主机是否需要独立背景资产；首期可以使用通用主机背景与原始型号文案回退。
- `remoteManagementEnabled` 和 `consoleStreamingEnabled` 返回 `nil` 的持续时间需要通过真机数据确认；设计已提供“同步中”状态。
- 多主机分页点在五台以上时应限制可见数量，建议最多显示五点并使用压缩边缘点。
- 存储数据缺少 `freeBytes` 时继续显示“X 个存储设备”，不保留空白占位。

## Candidate Follow-On Tasks

1. **简单任务：主机 Hero 色彩与照片层次增强**
   - 增加 Series X/S 环境底色、照片亮度对比度、底部渐变和分页点。
2. **简单任务：主机三行信息区与响应式布局**
   - 使用现有主机字段实现三行 Liquid Glass 信息，并覆盖 `nil` 状态。
3. **简单任务：状态操作区节奏调整**
   - 统一纯图标圆形 Liquid Glass 操作、状态电源切换、禁用态、下半屏间距与 Tab Bar 安全距离。
4. **简单任务：移动端视觉验收**
   - 覆盖 Series X/S、在线/待机/离线、单主机/多主机、深浅色和紧凑宽度。
