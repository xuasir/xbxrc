代码与自动验证完成，实机连续采样验收待用户执行。入口：控制器 → 触屏手柄 → 布局与输入测试 → 测试工具 → 采样诊断。

## 实现

- UIKit 读取 coalescedTouches，历史副本复用原始 UITouch 的 pointerID，并按源时间排列。
- 源 timestamp、接收 timestamp、状态完成 timestamp、处理 duration 与逐次状态边沿写入 JSON v2，时钟单位为 systemUptime 秒。
- 重复/过期移动单独计数；异常位置/时间的终止事件沿上一位置释放。生命周期取消与设备样本分开计数。
- recorder 2048 批环形缓冲，输入事件即时记录；面板和字符串最高 10Hz 刷新。指标分位数采用最近至多 4096 项，每指针指标保留最近十二个操作指针。
- 按压反馈与即时释放沿原有路径，通用与 Forza 两套布局继续可用。

## 实机验收动作

1. 每组开始用“清空输入”重置记录和指标。
2. 单指连续移动摇杆 15 秒，查看每指针源 Hz、P95/P99 与最大移动间隔。
3. 摇杆与油门同时操作 15 秒，穿插短按和多指释放；退出/后台后检查归零。
4. 使用“导出 JSON”保存统计；对照源 → 接收、源 → 状态、处理耗时及异常计数，记录设备与屏幕刷新设置。

当前输出终点为本地 recorder。真实串流的 8ms 轮询、发送节拍与远端反馈在后续端到端验收中测量。
