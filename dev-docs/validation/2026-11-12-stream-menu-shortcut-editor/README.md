## 交付行为

- 设置 → 串流体验的第一项为“串流菜单快捷键”，打开 `/setting/stream-shortcuts`。
- 子页复用当前页面背景，在内容区左上、左下分别放置实际串流菜单和诊断菜单图标；按钮和定位样式与串流页共用。
- 点击图标或绑定信息后独占录入，全部释放后保存；每组快捷键提供独立清空，允许两组同时未绑定。
- 清空、录入完成和取消后恢复目标焦点；返回时聚焦串流体验的配置入口。
