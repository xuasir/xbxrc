# 手机登录、通顶背景与串流快捷栏验收

2026-11-20，任务 `2026-11-20-ios-mobile-streaming-controls`。

登录空态统一为居中 96pt Xbox 标志和下方 52pt 高宽按钮。共用通顶背景从 320pt 提高到 380pt，主机图最大高度 260→300pt；画布上端覆盖率深色 42→36%、浅色 74→68%，中段 58→52%、84→78%。

串流通过双指从左右向内滑动或现有手柄/无障碍动作唤出，单击保持菜单收起。两条 52pt 窄栏采用 28% 黑色静态透明背景；左侧提供画面设置、声音、麦克风、比例、文字发送、结束及主机关机，右侧提供运行指标、诊断详情、诊断录制、导出和关闭。文字发送沿 PasteButton 的系统粘贴授权。结束与关机继续采用原生确认，系统分享继续沿 UIActivityViewController。

画面设置直接从底部上滑，保留比例、增强、色彩及默认值操作。诊断直接打开右上局部浮层及网络/显示/恢复/会话四组，背景采用 72% 黑色静态透明色。录制继续使用现有诊断 Trace。

播放器、页面壳层、快捷栏及画面设置只订阅必要字段。统计视图以每秒一次独立刷新；相同画面参数跳过 Metal 同步绘制请求。录制状态改为读取加锁活动标记，普通单指点击跳过双指拒绝日志。

手机 4 项 UI、iPad 3 项 UI、18 项单元测试、iPhoneOS 目标编译、前端 lint、Swift 格式、会话边界和 diff 检查通过。手机布局与操作分轮验收，来源及完整失败诊断见 validation.json、测试摘要和 failure-diagnostics.json。iPad XCTest 通用 pinch 生成垂直漂移并按合同拒绝；手机水平双指手势通过真实窗口合成输入验收。

截图为 DEBUG 正式控件夹具，渐变为本地测试背景，指标使用缺失值回退。夹具关闭自动收起计时以隔离 XCTest IPC 等待，正式菜单保留 5 秒。真实云游戏/主机串流持续播放时的菜单响应、画面供给与上屏长尾、音频及录制开始/结束接续用户重建实机复测。
